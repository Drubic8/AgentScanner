# Иконка ASIC Monitor

Знак: ASIC-чип с линией мониторинга. Общий рисунок для Windows и Android.

- `asic-monitor.svg` — редактируемый векторный оригинал, 108 × 108.
- `asic-monitor.png` — изображение 512 × 512 с прозрачными углами.
- Корневой `app.ico` — иконка Windows: 16, 20, 24, 32, 40, 48, 64, 96, 128 и 256 пикселей.
- Android: обычная иконка для Android 7, адаптивная для Android 8+ и одноцветная для тематических значков Android 13+.

Цвета: синий `#245EEA`, тёмно-синий `#10233F`, светлый `#F5FBFF`, мятный `#8CF5DF`.
В адаптивных вариантах знак уменьшен до безопасной области, фон обрезается системой под форму значка.

После изменения SVG запустите из окружения сборки с PyQt6 и Pillow:

```powershell
python scripts/generate_icons.py
```

Скрипт обновит ICO, PNG и XML-ресурсы Android. Пересборка EXE/APK выполняется отдельно;
замена ресурсов не меняет уже собранные файлы и опубликованные релизы.
