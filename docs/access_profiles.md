# Профили доступа к ASIC в Windows

GUI загружает профили при обычном запуске `gemini_gui.py` и в обновлённой EXE-сборке.
Отдельный диагностический запуск и повторный ввод стандартного пароля не нужны.

## Что работает сразу

При первом запуске доступны три включённых профиля:

| Профиль | Логин | Пароль | Авторизация |
|---|---|---|---|
| Antminer · Stock / PitBit | root | root | HTTP Digest |
| VNish · admin | Не требуется | admin | Получение Bearer-токена |
| VNish · root | Не требуется | root | Получение Bearer-токена |

Это общеизвестные стандартные учётные данные, а не пароли конкретной площадки.
VNish распознаётся до выбора его профилей. Статистика, открытая без авторизации,
читается без получения токена; для команд программа автоматически вызывает
`/api/v1/unlock`. При явном отказе авторизации проверяется следующий пароль VNish.
Управляющий запрос отправляется только после получения токена и не повторяется
при переборе профилей. При ограничении частоты запросов или сетевой ошибке перебор
паролей не продолжается.

## Настройка

Откройте **«Доступ к ASIC»**. В окне можно добавлять, редактировать, отключать,
удалять и упорядочивать профили. Пароль скрыт; его можно временно показать.

- **Устройства / прошивка** отделяет Antminer Stock от VNish и других семейств.
- **IP / подсети** принимает `*`, отдельные IPv4-адреса или CIDR-подсети через запятую.
  Пример: `10.33.6.0/24, 10.10.90.97`.
- Профили для конкретных адресов имеют приоритет над профилями `*`.
  Внутри каждой группы действует порядок списка, изменяемый кнопками «Выше» / «Ниже».
- За один опрос/вызов авторизации рассматривается не более трёх подходящих
  различных наборов доступа. Успешный вариант запоминается в текущем сеансе.
- Если перед открытием окна отмечены устройства, новый профиль получает их IP.
  Изменение существующего общего профиля по-прежнему применяется ко всей его области.
- Нажмите **«Сохранить профили»**, затем запустите сканирование.

Доступ к данным не разрешает автоматически непроверенные управляющие команды.
Соответствующий флажок действует только для отмеченных устройств и текущего сеанса.
Существующие явные настройки доступа через программный API сканера имеют приоритет
над автоматическим выбором; облачный агент и CLI не получают эти профили автоматически.

## Хранение

Профили сохраняются в `%LOCALAPPDATA%\ASICMonitor\access_profiles.dat` с помощью
Windows DPAPI, под текущей учётной записью Windows. Пароли не записываются открытым
текстом в JSON настроек, журналы или отчёты. Токены VNish остаются в памяти.
Сохранение атомарное: при ошибке шифрования предыдущий файл остаётся нетронутым.
Если файл невозможно расшифровать, GUI сообщает об ошибке и не заменяет его
стандартными профилями. Копирование EXE на другой компьютер не переносит пароли.

## Проверка 28.09.2026

- 107 автоматических тестов: выбор по IP/семейству, приоритеты, ограничение попыток,
  восстановление доступа, отсутствие повтора команды, Windows DPAPI и редактирование UI.
- Без ручной установки Credentials стандартные профили определили спящие D9,
  два S21+ и L7; работающий L9 / VNish 1.2.7 показал примерно 17 GH/s.
- Для L7 отсутствие числовой телеметрии во сне отображается прочерком. Статус
  Sleep определяется по прочитанной конфигурации, не по отсутствию хешрейта.

Старая EXE-сборка этих возможностей не содержит: необходимо использовать
пересобранный `dist/ASIC_Monitor.exe`.
