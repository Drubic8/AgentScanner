# ASIC Monitor 2.2.3

## Исправление VNish

При массовой подсветке часть устройств получала `skipped`: программа считала,
что модель или идентификатор устройства изменились между сканированием и командой.
HTTP и TCP могли возвращать разные обозначения одного L9 (`l9` и
`Antminer L9 (Vnish 1.2.6)`), а результат зависел от порядка ответов.

- Для VNish модель, версия прошивки, SN и MAC читаются из именованных полей `/api/v1/info`.
- Порядок ответов HTTP/TCP и название модели в телеметрии CGMiner больше не меняют идентификацию при доступной информации VNish.
- При наличии текущей прошивки и SN/MAC исчезновение CGMiner API не считается сменой устройства.
- Отсутствующий SN не подменяется серийным номером платы. Настоящая смена модели, прошивки, SN или MAC по-прежнему блокирует команду.
- Сохранены проверка совместимости управляющего интерфейса и защита от повторной записи LED.

Исправление входит в общее ядро Windows и Android. Массовая подсветка после
исправления требует визуальной проверки пользователем; автоматические тесты
не подтверждают физическую индикацию всех ASIC.
[Воспроизведение и проверки](https://github.com/Drubic8/AgentScanner/blob/main/docs/testing/vnish-identity-2026-10-04.md).

## Установка

Windows **2.2.2**: **Справка → Проверить обновления**, затем скачивание и подтверждение
установки после завершения сканирования и команд. Сети и настройки сохраняются.
Для 2.2.1 и более ранних версий скачайте EXE вручную.

Android APK устанавливается вручную. Это тестовая сборка Android 7.0+ для
`arm64-v8a` и `x86_64`. Разная тестовая подпись может потребовать удаления
предыдущей версии; заранее сохраните настройки и сети. Windows EXE пока не
подписан сертификатом издателя.

## English

Fixed false VNish bulk-command skips caused by HTTP/TCP identity differences.
Identity now uses named `/api/v1/info` fields for model, firmware, miner serial
and MAC. CGMiner display aliases and endpoint ordering no longer change identity
when VNish information is available. Real hardware or firmware changes still block
writes; missing serials are not replaced with board serials. The shared fix is
included in Windows and Android.

Windows 2.2.2 can install this release from Help → Check for updates. Older versions
require a manual EXE download. Android APK installation remains manual and test-signed.
