# ASIC Monitor 2.2.0 — Windows и Android

## Windows

- Компактная сводка с раскрытием деталей освобождает место таблице устройств.
- Настройки собраны в одном окне, включая доступ к ASIC; небольшая кнопка темы.
- Папки и вложенные группы подсетей, выбор нескольких сетей.
- Короткие названия столбцов, лампочка LED, фильтры состояния, модели, прошивки,
  подсветки и ошибок; сохранение расположения и ширины столбцов.
- Обновлённый журнал: поиск, фильтры, копирование и экспорт, ограничение размера.
- Групповые команды: раздельная отправка и проверка ответа, без повторных записей
  после таймаута. Сон и пробуждение доступны для смешанного парка по возможностям ASIC.

## Общее ядро устройств

- Доработана совместимость LED и режимов управления Stock Antminer, VNish и Elphapex.
- Улучшены чтение старых Antminer Z11/Z15/Z15e и обнаружение Jasminer.
- Проверены Sleep/Wakeup и LED Antminer S21 с PitBit.78 / incm.C074; исправлен
  ложный отказ на успешный код M000 и подмена текущего нуля историческим хешрейтом.
- Учитываются переходные состояния при засыпании. Поддержка конкретного режима
  определяется изученным интерфейсом и профилем, а не только названием модели.

## Android

- Компактный список и карточки, выбор отдельных ASIC и группы, доступные команды управления.
- Real Hash и Avg Hash, алгоритм, ошибки, состояние LED; сведения подробнее в карточке устройства.
- Фильтры модели, прошивки, состояния, LED и ошибок; поиск по IP и версии.
- Дерево папок сетей до четырёх уровней, выбор всей папки, сворачивание веток.
- Общий диспетчер групповых команд: до 16 одновременных отправок, отдельно проверка результата.
- Журнал нескольких операций в памяти сеанса, поиск и фильтр результата, экспорт CSV.
  Хранятся последние 1000 записей; число удалённых старых записей отображается.
- Все исправления ядра Windows включены в APK через общий пакет `miner_scanner`.

## Скачать

## Границы проверки

Команды требуют доступной локальной сети и подходящей учётной записи устройства.
Успешный ответ API не означает завершения разгона. Неизученные режимы не отправляются.
Аппаратные результаты конкретных прошивок описаны в [матрице испытаний](../testing/README.md).
Проверки общего ядра на ПК не заменяют испытания Wi-Fi/Ethernet/VPN на вашем телефоне.

APK остаётся тестовым и подписывается отладочным ключом сборки. Если Android
отклоняет обновление старого тестового APK из-за другого ключа, запишите сохранённые
сети, удалите старое приложение и установите новое. Данные удалённого приложения
будут потеряны. Постоянная подпись издателя остаётся отдельной задачей.
