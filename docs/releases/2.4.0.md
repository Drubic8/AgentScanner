# ASIC Monitor 2.4.0 — Antminer A3 и Goldshell HS5

## Новые устройства

### Antminer A3 Stock

- Модель, производитель Bitmain, версия прошивки и CGMiner API.
- Алгоритм Blake2B; текущий и средний хешрейт в GH/s, включая нулевые значения.
- Температуры и обороты вентиляторов.
- Исправлена обработка полного ответа STATS старой прошивки, в котором отсутствует запятая между объектами массива. Неполные ответы и неизвестные модели не принимаются как исправленные данные.

[Аппаратная проверка A3](../testing/antminer-a3-stock-2026-10-13.md).

### Goldshell MCB

- Добавлен профиль чтения, проверенный на Goldshell HS5 / Stock 2.2.1.
- Суммируется текущий и средний хешрейт всех плат; исходные MH/s переводятся в GH/s по подтверждённому формату API.
- Алгоритм читается из текущего выбора устройства: Blake2B-Sia для SC, Blake2B+SHA3 для HNS. Эти алгоритмы не объединяются с Blake2B A3.
- Читаются температуры плат, физический набор вентиляторов, активный пул, worker, uptime и состояние LED.
- Goldshell включён в фильтр «Остальные»; подпись фильтра обновлена для русского и английского интерфейса.
- Отсутствующий показатель платы не превращается в нулевой или частичный суммарный хешрейт. Нулевые обороты сохраняются. Нулевой хешрейт сам по себе не означает сон.

[Аппаратная проверка HS5](../testing/goldshell-hs5-2026-10-13.md).

## Проверки и ограничения

Добавлены обезличенные реальные ответы и тесты идентификации, единиц, датчиков,
повторного опроса, недоступного устройства, выбранного алгоритма, состояния LED,
JSON-массивов и отображения Goldshell в GUI. Все автоматические аппаратные тесты
используют подмены. Проверка реальных устройств выполнена только чтением.

Новый профиль не означает поддержку всех Goldshell или всех версий прошивок.
Команды управления Goldshell не заявлены. Новые команды A3 в этом выпуске не
сертифицированы. Исправления стабильности Windows и состояния WhatsMiner из
версии 2.2.5 сохранены.

Сети, папки, настройки и профили доступа остаются рядом с Windows EXE. При
замене приложения сохраните эти файлы; заменять нужно только EXE после закрытия
старой программы.

## Android

Версия Android синхронизирована: `versionName = 2.4.0`, `versionCode = 20400`.
Общее ядро содержит новые профили. APK собирается через GitHub Actions вместе
с Windows EXE и проходит lint и тесты на эмуляторе. Испытания новых моделей
на реальном телефоне проводятся отдельно от аппаратной проверки Windows.

## Проверка Windows-сборки

13.10.2026 собран Windows x64 EXE 2.4.0. Выполнены 416 автоматических тестов,
проверка запуска EXE без сети, экспорта PNG/CSV/XLSX/PDF, обновления с резервной
копией и подтверждением запуска, миграции настроек и повторного запуска с
сохранением вложенных сетей и путей отчётов. Проверено наличие нового профиля
Goldshell и его парсера внутри EXE. FileVersion и ProductVersion — 2.4.0.

Файлы публичного релиза собираются в GitHub Actions из тега `v2.4.0`; их
контрольные суммы находятся в `SHA256SUMS.txt`, прикреплённом к релизу. Локальная
и CI-сборка одного исходного кода могут иметь разные SHA256 из-за окружения
сборки. Предыдущий локальный EXE сохранён в `dist/archive`.

## English

Added Antminer A3 Stock scanning with Blake2B, GH/s rates, temperatures, fans and
bounded recovery of malformed legacy STATS JSON. Added the Goldshell MCB profile,
tested read-only on HS5 / Stock 2.2.1: combined board rates, current SC/HNS
algorithm, sensors, active pool, worker, uptime and LED state. Goldshell is
included in the Windows Others filter. Goldshell control commands are not yet
verified. Existing Windows stability and WhatsMiner state fixes are retained.
Android version is 2.4.0. Release APK builds, lint and emulator checks run in
GitHub Actions; testing the new models on a real phone is a separate step.
