# ASIC Monitor 2.6.0 — карточка устройства и чтение логов

Дата выпуска: **1 ноября 2026 года**. Изменения интерфейса в этом выпуске
относятся к Windows. Android остаётся на версии **2.5.0**.

## Карточка устройства

Откройте **Карточку устройства** для выбранного ASIC в таблице. Карточка содержит
снимок показаний на момент открытия: модель, прошивку, состояние, температуры,
вентиляторы, ошибки и доступные команды. На вкладке **Пулы** показаны настроенные
слоты 1–3 с адресами и worker. Пустые слоты сохраняют свои позиции; порядок
слотов не означает, что первый пул сейчас активен.

Снимок не подменяется в процессе чтения логов. Для свежих показаний повторите
сканирование и откройте карточку заново. Устаревшие показания явно помечаются.
Открытие карточки само по себе не запускает сетевой запрос.

## Логи устройства

На вкладке **Логи устройства** выберите тип и нажмите **Получить лог**.
Запрос выполняется в фоне, его можно отменить. Журналы не загружаются во время
каждого сканирования. Доступность определяется известным профилем API и ответом
прошивки, поэтому не гарантируется для всех моделей производителя.

| Семейство | Доступные журналы | Особенности |
| --- | --- | --- |
| Antminer Stock | Майнер, система/ядро | Известные HTTP-маршруты, сохранённые профили доступа |
| VNish | Майнер, система | REST API; при необходимости используется сессия VNish |
| WhatsMiner RPC 3 | Майнер, система | Текущие журналы из архива; до 60 секунд на загрузку и разбор |
| Elphapex DG1/DG1+ | Майнер | Текущий журнал; отдельный системный журнал пока не подтверждён |

Для Stock, VNish и Elphapex лимит ответа — **2 МиБ**, общий срок запроса — до
**20 секунд**. На проверенных Elphapex DG1/DG1+ текущий журнал доступен без пароля;
если другая прошивка требует входа, используются явно настроенные профили Elphapex.

WhatsMiner формирует и передаёт архив целиком. При большом текущем журнале
показываются последние полные строки в пределах **2 МиБ**, с явной пометкой
об ограниченном фрагменте. Архив ограничен **32 МиБ** в сжатом виде,
**128 МиБ** после распаковки и **512 записями**. Конфигурация и вложенные
исторические архивы не добавляются в просматриваемый текст; файлы архива
не извлекаются на диск.

Аппаратно подтверждены чтение архива WhatsMiner **M61S+ / API 3.0.5** и
текущего журнала Elphapex **DG1 / DG1_SW_V1.0.4**, **DG1+ / DG1+_SW_V1.0.4**.
Эти результаты не заменяют проверку других моделей и прошивок.

## Просмотр и передача диагностики

- Поиск по тексту, переход между совпадениями и копирование.
- Импорт сохранённых файлов UTF-8 или UTF-16 с BOM размером до 2 МиБ, в том
  числе для пока неподдерживаемых семейств. Импорт явно помечается; программа
  не проверяет, принадлежит ли файл выбранному ASIC.
- Сохранение очищенного лога в TXT и диагностического ZIP со сведениями об
  устройстве, временем снимка, статусом чтения и очищенным текстом.
- Предпросмотр ZIP перед сохранением. Известные пароли, токены, адреса,
  серийные номера и worker скрываются, но автоматическая очистка не гарантирует
  обнаружения всех личных данных. Перед передачей проверьте предпросмотр.

Исходный текст в просмотрщике может содержать личные данные. Экспорт использует
отдельную очищенную копию. Журналы не исполняются и не отображаются как HTML.
Неудачный новый запрос очищает прежний результат, чтобы старый текст не
выдавался за свежий лог. Отмена и закрытие окна ожидают завершения фонового чтения.

**Подключение внешнего ИИ и автоматическая отправка данных не реализованы.**
Диагностический пакет можно самостоятельно передать специалисту после проверки.

## Пулы и отчёты

Для таблицы и отчётов доступны отдельные поля **Pool/Worker 1–3**. Видимые поля
выбираются в настройках столбцов. Сведения берутся из ответа API; отсутствующие
данные не заполняются значениями соседнего слота.

## Установка и обновление

В [релизе v2.6.0](https://github.com/Drubic8/AgentScanner/releases/tag/v2.6.0)
скачайте **ASIC_Monitor.exe** и контрольные суммы **SHA256SUMS.txt**.
Windows также может обновиться через **Справка → Проверить обновления**.

При ручной замене закройте программу и замените только EXE. Сохраните рядом
`ip_ranges.json`, `app_settings.json` и `access_profiles.dat`: это ваши сети,
настройки и зашифрованные профили доступа. Windows EXE пока не подписан
сертификатом издателя.

Новый APK этим выпуском не выпускается: Android 2.5.0 доступен в
[предыдущем релизе](https://github.com/Drubic8/AgentScanner/releases/tag/v2.5.0).

Подробности: [руководство пользователя](https://github.com/Drubic8/AgentScanner/blob/v2.6.0/docs/user_guide.md),
[протоколы чтения и ограничения](https://github.com/Drubic8/AgentScanner/blob/v2.6.0/docs/development/device_logs.md),
[проверка WhatsMiner](https://github.com/Drubic8/AgentScanner/blob/v2.6.0/docs/testing/whatsminer-logs-2026-10-31.md),
[проверка Elphapex](https://github.com/Drubic8/AgentScanner/blob/v2.6.0/docs/testing/elphapex-logs-2026-10-31.md).

## English

Windows 2.6.0 adds device details with a fixed scan snapshot and three configured
pool/worker slots. Fetch logs on demand from supported Antminer Stock, VNish,
WhatsMiner RPC 3 and Elphapex interfaces. WhatsMiner archive retrieval allows
up to 60 seconds and shows the latest 2 MiB of large current logs; Elphapex
offers the current miner log only. Availability depends on the firmware response.

Search, copy or import text logs, then preview and save a redacted TXT log or
diagnostic ZIP. Review the cleaned text before sharing: automatic redaction
cannot identify every private value. No AI provider or automatic upload is
connected. Android remains at 2.5.0.
