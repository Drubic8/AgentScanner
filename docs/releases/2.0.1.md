# ASIC Monitor 2.0.1 — исправления и диагностика

Корректирующий выпуск после 2.0.0.

## Windows-приложение

- Исправлен захват скриншота: в буфер обмена копируются итоги и видимая таблица оборудования. Ранее захватывалась только таблица.
- Версия в заголовке PDF и меню «Что нового» теперь берётся из версии приложения.
- В проверку собранного EXE добавлены захват изображения из буфера обмена и проверка его размеров; также проверяются PDF, CSV и XLSX.

## Исходный проект и документация

- Добавлена команда `python -m miner_scanner.diagnostics`: разрешённые запросы чтения, повторные опросы, длительность запросов, ошибки и ZIP с обезличенными ответами API. Команда запускается из Python-окружения проекта, не через GUI EXE.
- Добавлена Excel-матрица испытаний по моделям и точным версиям прошивки: команды управления, длительный опрос, потеря связи, параллельность и отмена.
- Уточнены критерии подтверждения команд: HTTP 200 и таймаут сами по себе не подтверждают успешное выполнение.
- Удалены лишние записи MobileApp и вложенного репозитория pyasic; локальные справочные материалы и диагностические архивы исключены из Git.

## Проверки и ограничения

Автоматические проверки используют искусственные ответы и локальные эмуляторы.
Аппаратная совместимость конкретных моделей и прошивок требует заполнения матрицы
на реальных ASIC. Этот выпуск не объявляет команды аппаратно подтверждёнными.

## Публикация

Тег: `v2.0.1`. Название релиза: **ASIC Monitor 2.0.1 — исправления и диагностика**.
После успешной сборки приложите `dist/ASIC_Monitor.exe` и `dist/SHA256SUMS.txt`.
Сборка заново создаёт EXE и контрольную сумму; удалять всю папку `dist` не требуется.
Другие файлы в `dist` могут относиться к старым сборкам и не входят в этот релиз.
