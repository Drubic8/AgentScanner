# ASIC Monitor 2.2.4 — настройки рядом с EXE

## Windows

- Подсети, вложенные папки, настройки программы и зашифрованные профили ASIC сохраняются рядом с EXE.
- При первом запуске выбирается более свежий корректный файл рядом с EXE или из `%LOCALAPPDATA%\ASICMonitor`. Заменённые файлы сохраняются в `.settings-backup/`, прежний AppData остаётся на месте. Перенос выполняется один раз.
- Исправлено автоматическое сохранение языка, темы и компоновки таблицы при обычном запуске.
- Если папка недоступна для записи, программа показывает ошибку. Поместите EXE в свою папку, например «Документы\ASIC Monitor».

Обновление из 2.2.2/2.2.3: **Справка → Проверить обновления**. При ручном обновлении заменяйте только EXE. Для резервной копии сохраняйте файлы `ip_ranges.json`, `app_settings.json`, `access_profiles.dat`, `.asic-monitor-storage.json` и `.settings-backup/`. Удалённые ранее данные можно вернуть только из Корзины или резервной копии.

Пароли Windows DPAPI привязаны к учётной записи Windows. При переносе на другой ПК настройте доступ к ASIC заново. Паспорта устройств и журнал ядра остаются в SQLite в AppData.

## Android

Тестовый APK 2.2.4; хранилище Android и API устройств не изменены. APK устанавливается вручную.

## Проверки

Добавлены проверки вложенного дерева, путей PDF/XLSX, компоновки, двух запусков, миграции, резервирования и отказа записи. Сборка Windows проверяет готовый EXE на отдельной копии: перенос настроек и повторный запуск после удаления тестовых файлов AppData, а также автообновление и экспорт. Тесты используют синтетические адреса, не управляют реальным оборудованием.

## English

Windows settings, network folders and DPAPI-encrypted ASIC profiles now live beside the EXE. First launch migrates newer valid settings from former AppData with backups; later launches use sidecars only. Normal startup correctly persists language and table layout. Keep the EXE in a writable folder and back up its sidecars. Previously deleted data requires a Recycle Bin or backup restore. Scanner SQLite storage is unchanged. Android is versioned 2.2.4 without storage changes.
