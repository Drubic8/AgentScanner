# ASIC Monitor 2.2.1 — Иконка и язык интерфейса

## Изменения

- Новая иконка ASIC-чипа с линией мониторинга для Windows и Android.
- Windows ICO с 10 размерами; Android: обычная, адаптивная и одноцветная иконки.
- Общая настройка **Язык интерфейса / Interface language**: русский и английский.
- Переведены главное окно, настройки, подсети, фильтры, состояния, подсказки, меню,
  подтверждения управления и сообщения интерфейса. Журнал следует общему языку.
- Язык применяется без перезапуска. Данные сканирования, выделение, фильтры,
  имена сетей и события журнала сохраняются.
- При обновлении старый выбор языка журнала переносится в настройку интерфейса.

Короткие заголовки таблицы (`IP`, `LED`, `Model`, `Real Hash`, `Avg Hash`) общие для
обоих языков. Пользовательские названия, информация прошивки и исходные диагностические
сообщения устройств сохраняются в исходном виде.

## Где переключить язык

- Windows: **Инструменты → Настройки программы → Общие → Язык интерфейса → Сохранить**.
- Android: **Настройки → Язык интерфейса**. Выбор сохраняется автоматически.

## Файлы

- `ASIC_Monitor.exe` — Windows.
- `ASIC_Monitor-android-2.2.1-test.apk` — тестовый Android APK, Android 7.0+, arm64/x86_64.
- `SHA256SUMS.txt` — контрольные суммы файлов.

APK использует тестовую подпись CI. Если Android отклоняет обновление из-за другой
подписи, запишите сохранённые сети, затем удалите предыдущий тестовый APK и установите новый.
Постоянная подпись издателя требует отдельной настройки.

## English

New shared application icon and Russian/English throughout the Windows and Android
interface. Change the language in Settings. Live switching preserves scan results,
filters, selection and the journal. User names and raw device diagnostics remain unchanged.
The Android APK is a test build; its CI signing key may differ from earlier releases.
