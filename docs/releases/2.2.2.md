# ASIC Monitor 2.2.2

## Windows

- Обновление EXE из программы: **Справка → Проверить обновления**. Скачивание идёт в фоне, его можно отменить.
- Загрузка привязана к конкретному опубликованному релизу GitHub. Перед установкой проверяются размер, SHA256 и версия EXE.
- Установка требует подтверждения и завершения сканирования и команд. Отдельный процесс ждёт закрытия приложения, сохраняет прежний EXE и заменяет файл.
- Если новая программа не подтверждает запуск, помощник восстанавливает прежний EXE. Сети, настройки и профили доступа остаются в пользовательской папке.
- Добавлены проверки повреждённых файлов, отмены, восстановления и замены собранного EXE с запуском новой программы.

**Переход с 2.2.1:** скачайте `ASIC_Monitor.exe` один раз вручную. Обновление из программы доступно начиная с 2.2.2. Автоматическую проверку наличия новой версии можно включить в общих настройках; установка всегда запрашивает подтверждение.

EXE необходимо хранить в папке, доступной для записи текущему пользователю. Прав администратора помощник не запрашивает. Контрольная сумма подтверждает соответствие файлу релиза; дистрибутив пока не подписан сертификатом издателя.

## Android

Обновлена версия до 2.2.2; функциональность Android остаётся прежней. APK устанавливается вручную, Windows-механизм обновления к нему не применяется. Это тестовая сборка Android 7.0+ для `arm64-v8a` и `x86_64`, с тестовой подписью. При несовпадении подписи предыдущей сборки Android потребует её удаления; заранее сохраните настройки и сети.

## Файлы

- `ASIC_Monitor.exe` — Windows x64.
- `ASIC_Monitor-android-2.2.2-test.apk` — тестовая сборка Android.
- `SHA256SUMS.txt` — контрольные суммы обоих файлов.

## English

Windows now downloads and installs updates from the app after confirmation. Downloads are pinned to a published GitHub release and checked for size, SHA256 and EXE version. Installation waits for device operations to finish, saves the previous executable and restores it if the new app fails to acknowledge startup. Settings and networks are preserved. Install 2.2.2 manually once when upgrading from 2.2.1. The executable is not publisher-signed.

Android receives a version bump only; APK installation remains manual. This is a test-signed Android 7.0+ build. Different test signatures may require uninstalling the previous APK; back up your settings first.
