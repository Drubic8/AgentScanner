# ASIC Monitor 2.2.5 — стабильность и состояние WhatsMiner

## Windows

- Исправлено удаление активного элемента Qt при переключении галочки в дереве подсетей. Настройки сохраняются сразу, пересоздание дерева отложено до завершения обработки события. Быстрый выбор нескольких сетей сохраняется полностью.
- Исправлена сортировка чисел, пустых и некорректных значений. Обновление таблицы блокирует сигналы выделения и восстанавливает сортировку даже при ошибке.
- Добавлена локальная диагностика падений в папке `diagnostics` рядом с EXE. Сохраняются стеки вызовов без значений переменных и сообщений исключений. Хранятся шесть последних запусков.
- WhatsMiner RPC 3.0 с остановленным сервисом (`working=false`) распознаётся как сон даже при отсутствии summary или нулевом uptime. Остаточный хешрейт отображается как засыпание; аппаратные ошибки сохраняются отдельно.

Обновление из 2.2.4: **Справка → Проверить обновления**. При ручной установке закройте программу и замените только `ASIC_Monitor.exe`, сохранив файлы настроек рядом с ним.

## Android

Тестовый APK 2.2.5 включает исправление состояния WhatsMiner в общем ядре. Изменения Windows/Qt не относятся к Android. APK устанавливается вручную.

## Проверки и ограничения

Добавлены проверки времени жизни элемента дерева при галочке, быстрых последовательных изменений, сортировки, восстановления таблицы после ошибки и безопасного журнала исключений. Реальный ответ спящего M61S+_VL30 (API 3.0.5, прошивка 20260729.11.Rel2) проверен только чтением и сохранён в обезличенной регрессионной фикстуре.

Сбой EXE 2.2.4 от 11 октября 2026 года произошёл в `Qt6Widgets.dll`, код `0xc0000005`. Сопоставление с той же DLL показывает участок `QTreeWidgetItem::setData`; в старом обработчике галочки дерево синхронно удаляло активный элемент. Исправление устраняет этот дефект времени жизни. Без дампа памяти нельзя доказать, что все возможные падения имели одну причину; новая диагностика поможет проверить повторный сбой.

## English

Fixed unsafe subnet tree rebuilding inside Qt checkbox handling while preserving rapid edits. Fixed mixed-value sorting and guarded table refreshes. Added local stack-only crash diagnostics beside the EXE. WhatsMiner RPC 3 recognizes stopped services with zero uptime. Android includes the scanner fix; Windows-specific Qt changes do not apply to Android. Update through Help → Check for updates, or replace only the EXE after closing the program.
