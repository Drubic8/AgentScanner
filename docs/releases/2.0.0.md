# ASIC Monitor 2.0.0

Локальный мониторинг ASIC для Windows x64.

## Интерфейс

- Новое оформление со светлой, тёмной и системной темами.
- Поиск и фильтрация устройств; удобные состояния сканирования.
- Отдельные разделы настроек: сканирование, таблица, PDF и Excel/CSV.
- Сохранение темы и плотности таблицы, управление параллельностью опроса.
- Настройки в папке пользователя Windows сохраняются при замене EXE.
- Исправлены сортировка экспортируемых данных и подключение завершения сканирования. PDF поддерживает кириллицу и помещает таблицу в ширину страницы.

## Ядро

- Профили моделей и прошивок, разделение сетевого обмена и разбора ответов.
- Кэш идентификации, постепенное отображение результатов и отмена сканирования.
- Паспорта устройств, последние снимки и журнал команд.
- Управление через определённый профиль; неподтверждённые команды по умолчанию отключены.

## Установка

Скачать `ASIC_Monitor.exe` и запустить. Python устанавливать не требуется. Для обновления закрыть прежнюю версию и заменить EXE. Проверка обновлений находится в меню «Справка»; новая версия скачивается через браузер.

Для сканирования нужен доступ к локальной сети ASIC. Логин и пароль задаются кнопкой «Доступ к ASIC» на текущий сеанс.

## Проверка совместимости

Интерфейс и экспорт проверены на искусственных данных; аппаратная совместимость конкретных моделей и версий прошивок требует испытаний. Поддержка всех прошивок не заявляется. Android в этот выпуск не входит.
