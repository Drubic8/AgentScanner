# ASIC Monitor 2.0.3

Обновление управления сетями в локальной Windows-программе.

## Что изменилось

- Новый редактор: название сети, удобное поле адресов, подсказки форматов, проверка при вводе и подсчёт уникальных IP до сохранения.
- Вставка нескольких диапазонов с разделением строками, запятыми или точкой с запятой. Поддерживаются одиночный IPv4, CIDR и интервалы.
- Сообщения об ошибках с номером строки. Пересечения считаются один раз, показывается число повторов. Лимит задания — 4096 IP.
- Поиск по сохранённым названиям и диапазонам. Галочки выбирают сети для сканирования; выбор сохраняется между запусками.
- Выделение строки предназначено для редактирования и не меняет набор сетей для сканирования. Если снять все галочки, программа предложит выбрать сети.
- Подтверждение удаления и сохранение прежнего списка при ошибке записи файла.
- Совместимость со старыми файлами диапазонов. Пользовательские настройки не включаются в дистрибутив и не удаляются при обновлении.

## Обновление

Закройте предыдущую версию и замените EXE. Сети и настройки остаются в `%LOCALAPPDATA%\ASICMonitor`.

В релиз нужно прикрепить `ASIC_Monitor.exe` и соответствующий `SHA256SUMS.txt` из `dist`. Тег `v2.0.3` должен указывать на коммит, где GUI, `version.json` и `pyproject.toml` содержат версию `2.0.3`.

## Ошибка прежней сборки GitHub

Запуск [Windows EXE №2](https://github.com/Drubic8/AgentScanner/actions/runs/35088608757) завершился на шаге `Validate tag`: тег `v2.0.1` указывал на коммит `4c10407` с версией `2.0.0`. Сообщение: `Tag must match version.json`. Сборка EXE в этом запуске не начиналась.

После исправления тега [запуск №3](https://github.com/Drubic8/AgentScanner/actions/runs/35125484082) для коммита `33a2936` завершился успешно. Повторный запуск старой ошибочной сборки не нужен.

## Границы проверки

Диапазоны и интерфейс проверяются локально, включая синтетическое сканирование и экспорт. Доступ к реальным ASIC с этого компьютера отсутствует: совместимость прошивок и команды требуют аппаратных испытаний по существующей матрице.
