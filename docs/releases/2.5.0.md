# ASIC Monitor 2.5.0 — массовые команды и читаемый интерфейс

## Windows

### Проверка перед отправкой

- При выборе команды открывается список выбранных ASIC. Программа параллельно
  читает актуальные сведения и показывает готовность каждого IP: готово, нет
  связи, нужен доступ, действие не поддерживается или изменился паспорт устройства.
- Команда не отправляется до нажатия **Отправить для N**. В пакет входят только
  готовые адреса исходного выбора. Права записи API проверяются при отправке;
  предварительная готовность не гарантирует принятие запроса устройством.
- Перед записью повторно проверяется исходный fingerprint. Обновление кэша между
  выбором и отправкой не позволяет обойти проверку сменившегося ASIC или прошивки.

### Результат для каждого устройства

- Раздельные колонки **Принято API**, **Результат**, **Подробности**. Принятие
  запроса без прочитанного целевого состояния остаётся **Не подтверждено**.
- Поиск и фильтр **Только проблемы**, полный текст результата под таблицей.
  Кнопка **Результаты команды** под основной таблицей повторно открывает последнее
  окно в текущем сеансе.
- **Повторить неудачные** снова проверяет только адреса с безопасным исходом:
  отмена до записи, пропуск или явный отказ API. Успешные и неопределённые команды
  не повторяются автоматически. Изменение выделения таблицы не расширяет пакет.
- **Остановить** отменяет ожидающие действия; уже выполненные команды не отменяются.
  Ошибка одного задания не прерывает остальные. Подтверждение API сохраняется
  даже при последующем сбое очереди.
- HTTP 5xx после управляющего запроса не считается доказанным отказом и не даёт
  права повторять запись. Целевое состояние уточняется чтением API, если команда
  поддерживает такую проверку.

### Шрифт и отчёты

- В **Настройки → Общие → Шрифт и читаемость** доступны установленные шрифты,
  размер интерфейса 11–20 px и отдельный размер таблиц 10–24 px.
- Компактные выпадающие списки, готовые размеры и ручной ввод, предпросмотр и сброс.
  Настройки сохраняются рядом с EXE и применяются без перезапуска. Строки таблиц
  и боковая панель подстраиваются под текст.
- Исправлены перевод счётчиков с повторяющимися полями и защита CSV/XLSX:
  строки устройства сохраняются как данные, а потенциальные формулы нейтрализуются.

## Android

Версия синхронизирована до **2.5.0 / 20500**, обновлено общее ядро сканера.
Новые окна проверки и настройки шрифта в этом выпуске относятся к Windows.
Мобильное приложение сохраняет прежний интерфейс и способ тестовой подписи APK.
Файл выпуска: `ASIC_Monitor-android-2.5.0-test.apk`.

## Установка и обновление

Windows: **Справка → Проверить обновления** или замена только
`ASIC_Monitor.exe` после закрытия программы. Сохраните рядом `ip_ranges.json`,
`app_settings.json` и `access_profiles.dat` — это ваши сети, настройки и доступы.

Android: установите APK вручную. Если Android сообщает о несовпадении подписи,
установка поверх прежней сборки невозможна; удаление приложения стирает его
локальные данные, поэтому заранее сохраните нужные сведения.

`SHA256SUMS.txt` содержит контрольные суммы EXE и APK. Windows EXE пока не подписан
сертификатом издателя. Автоматические проверки и проверка собранного EXE используют
искусственные данные; они не подтверждают поддержку всех моделей и прошивок ASIC.
