# ASIC Monitor 2.7.0 — пулы и workers

Дата выпуска: **16 ноября 2026 года**. Изменения относятся к Windows.
Android остаётся на **2.5.0**:
[предыдущий тестовый APK](https://github.com/Drubic8/AgentScanner/releases/tag/v2.5.0).

## Настройка пулов

В меню управления выбранными ASIC доступен редактор пулов с отдельными
настройками URL, worker и пароля для каждого из трёх слотов. Можно сохранить
текущее значение либо явно заменить его; пустой пароль задаётся отдельно.

Общее имя worker до точки одинаково у выбранных устройств. Суффикс можно
сформировать по полному IP, последнему числу адреса или порядковому номеру,
в том числе с ведущими нулями. Предпросмотр фиксирует соответствие устройств
и имён, проверяет совпадения и показывает результат для каждого ASIC.

Перед отправкой программа заново проверяет устройство и конфигурацию.
Нетронутые слоты и параметры сохраняются по изученному контракту.
Отмена и частичные ошибки учитываются отдельно; неопределённая команда
автоматически не повторяется. Введённые пароли не попадают в отчёт совместимости.
Буквальные пароли `***`/`•••` можно задать явно; маскоподобный ответ API
не считается доказательством сохранения такого пароля.

Исправлен перезапуск упакованной программы при автообновлении. Проверены
замена EXE, резервная копия, подтверждение запуска и перенос настроек.

## Совместимость и границы проверки

Реализованы отдельные ветки для изученных Bitmain Stock, VNish settings,
WhatsMiner RPC3, DG1+ V1.0.4 и PitBit S21+_i / incm.C096 / API 3.1.
Допуск определяется фактическим интерфейсом и конфигурацией, а не одним
названием модели. [Матрица совместимости](../development/pool_configuration.md).

WhatsMiner требует явно задать пароли всех трёх слотов, права API Write
и пустой автоматический суффикс. Runtime-чтение не возвращает пароли,
поэтому результат записи остаётся «Не подтверждено».

На одном **S21+ Stock FR-1.15(250422-S21+)** проверено изменение worker
третьего слота с сохранением остальных настроек и последующее восстановление
исходного worker отдельным планом. Изменение URL/паролей, группа устройств,
сохранение после reboot и зачисление shares этим испытанием не проверены.
Аппаратная запись остальных веток также остаётся отдельной проверкой.
