# ASIC Monitor 2.4.1 — порядок сетей и ширина столбцов

## Windows

- Перетаскивайте подсети и папки между строками для изменения порядка, на папку — для переноса внутрь, в свободную область внизу — для переноса в корень.
- Для одной выбранной строки доступны стрелки, контекстное меню и Alt+↑/↓/←/→: выше, ниже, на уровень выше, внутрь предыдущей папки. Для нескольких строк используйте Shift/Ctrl и перетаскивание или «Переместить в папку…».
- Папка переносится целиком с вложенными сетями. Галочки сохраняются. Перенос в саму себя или дочернюю папку и конфликт имён отклоняются. При ошибке сохранения прежний порядок остаётся на месте.
- После сканирования ширина видимых столбцов подбирается по полному содержимому, включая длинные worker. Используйте горизонтальную прокрутку. LED остаётся компактным.
- Автоподбор включён по умолчанию. Чтобы сохранить ручную ширину, отключите «Подбирать ширину столбцов после сканирования» в настройках таблицы или меню правого щелчка заголовка. В этом меню доступны подбор одного или всех столбцов. Двойной щелчок по границе заголовка также подбирает ширину.
- Ручная ширина, в том числе более 1200 px, сохраняется между запусками отдельно для обычного и компактного режима. Полный текст ячейки доступен при наведении.
- Новые элементы поддерживают русский и английский языки.

## Исправление KS5

У KS5/KS5 Pro Stock положительный **текущий** хешрейт имеет приоритет над
сохранившимся `bitmain-work-mode = 1`: майнящий ASIC больше не отображается как
спящий по одному этому полю. Средний хешрейт не используется как доказательство
текущего майнинга. Приоритеты состояния других моделей не изменены.

## Android

Номер версии синхронизирован: `2.4.1` / `20401`. Общее ядро содержит исправление
состояния KS5. Перетаскивание дерева и настройки ширины в этом выпуске относятся
к Windows. APK сохраняет существующий способ тестовой подписи; это не новый
набор функций мобильного интерфейса.

## Обновление

В Windows используйте **Справка → Проверить обновления** либо закройте программу
и замените только `ASIC_Monitor.exe`. Сохраните рядом с EXE `ip_ranges.json`,
`app_settings.json` и `access_profiles.dat`: в них находятся ваши сети, настройки
и доступы. Формат дерева совместим с предыдущей версией.

Файлы EXE, APK и `SHA256SUMS.txt` публикуются из тега `v2.4.1` после проверок
GitHub Actions. Проверки интерфейса и сканера используют демонстрационные данные
и подмены; новых команд реальному оборудованию для этого выпуска не отправляли.
