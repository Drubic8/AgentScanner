## Точный контракт старой формы

`f_get_miner_conf` переносит `ant_data.pools` в поля страницы;
`f_submit_miner_conf` читает их и вызывает
`jQuery.ajax` с POST `/cgi-bin/set_miner_conf.cgi`.
Тело — объект данных формы из 15 полей:

| Источник | Поля запроса |
| --- | --- |
| `pools[0].url/user/pass` через DOM | `_ant_pool1url`, `_ant_pool1user`, `_ant_pool1pw` |
| `pools[1].url/user/pass` через DOM | `_ant_pool2url`, `_ant_pool2user`, `_ant_pool2pw` |
| `pools[2].url/user/pass` через DOM | `_ant_pool3url`, `_ant_pool3user`, `_ant_pool3pw` |
| Состояние checkbox beeper | `_ant_nobeeper` |
| Состояние checkbox temperature override | `_ant_notempoverctrl` |
| Состояние checkbox ручного вентилятора | `_ant_fan_customize_switch` |
| Текстовое поле вентилятора | `_ant_fan_customize_value` |
| `ant_data["bitmain-freq"]` | `_ant_freq` |
| `ant_data["bitmain-voltage"]` | `_ant_voltage` |

Это **не JSON**: локальный jQuery 1.10.2 использует `processData:true`
и `application/x-www-form-urlencoded; charset=UTF-8`.
`dataType:'json'` задаёт разбор ответа. В странице, xhr.js и json2
не обнаружены изменения этих настроек сериализации.

## Почему сохранение остальных настроек не доказано

Из шести непуловых полей запроса только частота имеет прочитанное
исходное значение. Остальные пять исходных параметров отсутствуют:

| Отсутствующий параметр чтения | Что сформировала бы неизменённая форма |
| --- | --- |
| `bitmain-nobeeper` | checkbox включён; строка `false` в `_ant_nobeeper` |
| `bitmain-notempoverctrl` | checkbox включён; строка `false` в `_ant_notempoverctrl` |
| `bitmain-fan-ctrl` | checkbox выключен; строка `false` в `_ant_fan_customize_switch` |
| `bitmain-fan-pwm` | пустое `_ant_fan_customize_value` |
| `bitmain-voltage` | пустое `_ant_voltage` |

Статическая начальная заготовка напряжения не сохраняется: затем код
безусловно читает отсутствующее свойство `ant_data`, получая `undefined`
без исключения. Локальный jQuery сериализует `undefined/null` в пустую
строку; `.val(undefined)` также очищает текстовое поле.
Это значения, выводимые из UI по умолчанию, а не прочитанные настройки.
Пять имеющихся `api-*`/`bitmain-use-vil` полей форма вообще не пересылает.

Нельзя безопасно скопировать полное тело с этими defaults или отправить
только девять полей пулов: поведение setter при опущенных параметрах
не установлено. Нужен источник фактических пяти значений либо доказанный
серверный контракт сохранения непереданных параметров.

Обработчики и success, и error только перезагружают страницу.
Тело ответа не проверяется; ack, сохранение, необходимость применения
и перезапуска неизвестны. Явной команды reboot в submit-функции нет,
но это не доказывает отсутствие серверного перезапуска майнера.

найти присваивание `ant_data`, разобрать его JSON-значение ограниченным
`JSONDecoder.raw_decode`, заменить **весь объект** строковым литералом

`d2a46a4d1b321a557b18470e88dd7ac92d69b289da8e6d88b3a1e0735c4e6e54`.

указанный хеш относится именно к нормализованному шаблону без настроек.
Он фиксирует источник анализа, а не автоматически разрешает запись.
