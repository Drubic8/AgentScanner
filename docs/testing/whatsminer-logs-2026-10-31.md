# WhatsMiner: чтение текущих журналов через RPC 3

Проверено 31.10.2026 на одном устройстве с разрешения владельца. Этот отчёт
содержит только технические результаты; IP, серийные номера и строки журналов
в него не включены.

| Параметр | Значение |
| --- | --- |
| Модель по API | `M61S+_VL30` |
| Прошивка | `20260729.11.Rel2` |
| API | `3.0.5` |
| Профиль сканера | `microbt.rpc3` |
| Запрос архива | `get.log.download`, TCP 4433 |
| Размер полученного архива | 17 759 188 байт |
| Время запроса | 31,79 с |

## Протокол и результат

Использован рабочий адаптер `miner_scanner.device_logs`, а не отдельная
реализация загрузки. Контракт соответствует официальной
[документации Log API](https://apidoc.whatsminer.com/#api-Log-get_log_download):
запрос JSON и начальный JSON-ответ передаются с четырёхбайтовой длиной
little-endian; затем на том же соединении поступает сырой gzip-архив размера
`msg.logsize`. Логин, пароль и токен для чтения не передавались.

Из одного полученного архива прочитаны два текущих файла в каталоге
`<device>.logs`. Повторного сетевого скачивания для проверки системного журнала
не выполнялось: он разобран локально из того же архива.

| Выбранный журнал | Результат | Возвращённый текст UTF-8 | Число строк | Ограничение |
| --- | --- | --- | --- | --- |
| `miner-state.log` | `succeeded` | 2 097 108 байт | 30 373 | Конец файла, `truncated=True` |
| `system.log` | Успешный разбор того же архива | 2 097 119 байт | 16 982 | Конец файла, `truncated=True` |

Оба текущих журнала больше лимита отображаемого текста. Сохранены последние
полные строки в пределах 2 МиБ. Конфигурационные файлы, вложенные ZIP/GZ и
исторические журналы не использованы как текст текущего журнала; содержимое
архива не извлекалось в каталог на диске.

Диагностический пакет сформирован. Проверены скрытие адреса выбранного
устройства и сохранение признака `truncated`. Это проверка конкретного пакета,
а не гарантия обнаружения всех возможных персональных данных в произвольном
журнале: перед передачей остаётся необходимым просмотр очищенного содержимого.

После загрузки отдельный запрос `get.device.info` вернул `working=true`.
Команды управления, изменение настроек и очистка журналов в эту проверку
не входили.

## Границы подтверждения

Аппаратная проверка относится к указанным модели и прошивке. Поддержка других
WhatsMiner с профилем `microbt.rpc3` определяется их ответом на этот интерфейс;
прочие поколения API данным адаптером не подтверждены. Отсутствие текущего
файла или неподдерживаемый формат архива не считается успешным пустым журналом.

Лимиты реализации: 60 секунд на загрузку и разбор, 64 КиБ на начальный JSON,
32 МиБ на gzip, 128 МиБ на распакованный TAR, 512 записей, 2 МиБ на возвращаемый
текст. Фрагментация сокета, отмена, отказы API, повреждённые архивы, лимиты и
небезопасные записи проверяются отдельно подменными тестами
`tests/test_whatsminer_device_logs.py` и `tests/test_whatsminer_log_archive.py`.
