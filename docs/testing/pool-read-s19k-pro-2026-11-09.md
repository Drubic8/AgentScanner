# S19k Pro Stock: чтение формы настройки пулов

Дата: **9 ноября 2026 года**. Пользователь отдельно разрешил только чтение
выбранного устройства. Псевдоним — `pool-s19k-001`; реальные IP, MAC/SN,
пулы, workers, пароли и профили доступа в документ не включены.

## Устройство и выполненные действия

Подтверждены Antminer S19k Pro, Bitmain, Stock
`Wed Nov 15 14:47:56 CST 2023`, профиль `bitmain.stock` v2.
Версия CGMiner API и хешрейт не запрашивались. Принадлежность к варианту
120T из списка оборудования не устанавливалась.

Сетевая проверка ограничена HTTP GET идентификации, конфигурации,
`miner.html`, `index.html` и локальных статических JS, объявленных этими
страницами. POST, CGI управления, TCP и переходы на другие устройства
запрещены отдельным guard до обращения к сети. Guard проверен локально.
Профили доступа прочитаны через обычный защищённый API приложения только
для выбранного адреса; их значения не печатались и не экспортировались.

Получены три пула со строковыми `url/user/pass`. Пароли присутствуют,
но их значения не сохранялись. Другие поля конфигурации:

| Поля | Наблюдённый тип |
| --- | --- |
| `api-listen`, `api-network`, `bitmain-fan-ctrl`, `bitmain-use-vil` | boolean |
| `api-groups`, `api-allow`, `bitmain-fan-pwm`, `bitmain-freq`, `bitmain-voltage`, `bitmain-ccdelay`, `bitmain-pwth`, `bitmain-work-mode`, `bitmain-freq-level` | string |

## Изученная форма

- `/miner.html`: SHA256 `87cdcad208890741cc424c477219094ff57cb5783b2f2e2843ea641fde550128`.
- `/js/miner.8380a5.js`: SHA256 `f7cdaa3b4ebbb11b2afe7a39982818ee82f5c733bb36553e6a643e7f7046057e`.
- `/js/index.db9b87.js`: SHA256 `0b06b3ea59dde751bb8afb2128f8c9ddab6c35465c6e75d9a780626adf07869d`.

JS анализировался статически и не исполнялся. `initData` копирует три
`pools` с `url/user/pass`, `bitmain-fan-ctrl`, `bitmain-fan-pwm`,
`bitmain-work-mode` в `miner-mode`, `bitmain-freq-level` в `freq-level`.
`saveMineSet` сериализует только этот `minerForm` в JSON для
`POST /cgi-bin/set_miner_conf.cgi`. Сам запрос **не отправлялся**.

Текущее значение режима форма копирует без преобразования типа.
Новый контракт сохраняет этот тип через `preserve_mode_type`, требует
точные HTML/JS и не допускает fallback только по похожим полям.
В запись `modes["S19k Pro"]` не добавлены команды питания. Наличие строки
HEM в JS не превращается в разрешение изменять режимы в рамках этой задачи.

## Границы результата

Обезличенные метаданные чтения, audit и очищенные статические файлы находятся
в локальном архиве проверки; проверка с новым контрактом —
`20261109T124257Z-3513b18d`. Её audit содержит 14 HTTP GET и ноль записей.
Исходные настройки и
полные ответы устройства не сохранялись. Fixture проекта содержит
[синтетические значения с наблюдёнными именами полей и типами](../../tests/fixtures/pool_s19kpro_read_20261109.json).

Подготовка изменений worker и пароля и формирование запроса проверяются
в памяти и на локальном имитаторе. Проверяется точная форма запроса,
сохранение типа текущего режима, параметров вентилятора, уровня частоты
и двух нетронутых слотов. В `dry-run.json` для IP и порядкового номера все эти
проверки завершились `true`, `setter_called=false`. Локальные сценарии находятся
в [тестах S19k Pro](../../tests/test_pool_s19kpro_observed.py).
Такая проверка не доказывает приём, постоянное
сохранение или применение настроек реальным устройством.
