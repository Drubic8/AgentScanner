# Antminer L9: подсветка на двух дополнительных интерфейсах

Проверено 01.10.2026 после массовой команды, где 6 из 18 устройств
получили `unsupported`. Команды блокировал каталог совместимости:
SHA-256 двух вариантов `index.*.js` отсутствовали в нём.

| Адреса | Системная сборка | Интерфейс |
| --- | --- | --- |
| 10.33.221.6, .7, .9, .14 | Wed Dec 4 15:40:03 CST 2024 | index.084178.js |
| 10.33.221.5, .8 | FR-1.19(260302-L9) | index.acb1b2.js |
| 10.33.221.10 — контрольное чтение | Mon Feb 10 10:01:06 CST 2025 | index.d5a821.js — уже поддержан |

В обоих новых интерфейсах подтверждены те же команды:

- `POST /cgi-bin/blink.cgi`, тело `{"blink":true/false}`;
- проверка через `GET /cgi-bin/get_blink_status.cgi`, логическое поле `blink`;
- интерфейс также содержит `GET /cgi-bin/reboot.cgi`; аппаратная перезагрузка
  в этой проверке не выполнялась.

В `miner_scanner/profiles/stock_interfaces.json` добавлены SHA-256:

- `index.084178.js`: `549a734b3cf9f7d07f58216a10440dc06274ca2a731bd560ac44a4bc25c693ca`;
- `index.acb1b2.js`: `0bf71a8325adedb942b82f0333a919a28a4675f4266811421e4c8f0349bec273`.

После исправления `led_on` отправлен через `execute_command` каждому из шести
адресов: все команды получили `succeeded`, API принял запись и подтвердил
`blink=true`. Подсветка оставлена включённой согласно исходной команде пользователя.
Уже при первом чтении эти устройства сообщали `blink=true`, поэтому результат
подтверждает приём команды и состояние API, а не видимое мигание индикатора.
Визуальная проверка оператором ещё не зафиксирована.

Текст ошибки при блокировке теперь говорит, что совместимость не подтверждена,
без утверждения об отсутствии функции у ASIC.
Регрессионный тест проверяет включение/выключение на обоих интерфейсах
и блокировку после изменения их содержимого. EXE не пересобирался.
