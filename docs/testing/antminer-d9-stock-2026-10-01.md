# Antminer D9: управление Stock API

Проверено 01.10.2026 на `10.33.8.3`, прошивка
`Tue May 28 09:27:48 CST 2024`. До проверки: Normal, около 1807 GH/s.

## Результаты

| Команда | Проверка результата |
| --- | --- |
| Подсветить | API подтвердил `blink=true`; визуальная проверка индикатора не выполнялась |
| Выключить подсветку | API подтвердил `blink=false` |
| Sleep | Прочитан `bitmain-work-mode="1"`; следующее сканирование показало Sleep и 0 GH/s |
| Normal | Прочитан `bitmain-work-mode="0"` |
| Перезагрузка | API принял запрос; устройство стало недоступно и вернулось в сеть с режимом `0` |

После перезагрузки: Normal, подсветка выключена. Сравнение конфигурации
подтвердило сохранность пулов, настроек вентиляторов, частоты, напряжения
и уровня частоты. Достижение рабочего хешрейта после разгона отдельно
не подтверждено: в первом итоговом сканировании ещё 0 GH/s и `NO HASH`.

## Протокол

- Подсветка: `POST /cgi-bin/blink.cgi`, JSON `{"blink":true/false}`;
  проверка через `GET /cgi-bin/get_blink_status.cgi`.
- Перезагрузка: `GET /cgi-bin/reboot.cgi`, без параметров и повторов.
- Режим: `POST /cgi-bin/set_miner_conf.cgi`, `miner-mode=1` для Sleep,
  `miner-mode=0` для Normal. Чтение режима из `bitmain-work-mode`.
- При записи режима сохраняются `pools`, `bitmain-fan-ctrl`, `bitmain-fan-pwm`,
  `bitmain-freq`, `bitmain-voltage`. Поле `bitmain-freq-level` переносится
  в `freq-level`, включая пустую строку, как в интерфейсе устройства.
- `algo` читается, но веб-интерфейс не отправляет его при сохранении.

Sleep может примениться после таймаута HTTP-записи. В таком случае
исполнитель читает режим отдельно и не повторяет запись автоматически.
`unconfirmed` не означает гарантированный отказ: перед следующей командой
нужно проверить текущее состояние устройства.

## Определение совместимости

В `miner_scanner/profiles/stock_interfaces.json` добавлены проверенные интерфейсы:

| Файл | SHA-256 |
| --- | --- |
| `miner.dc8dd8.js` | `f6a77087e1b0ac2389bb3d44afb057f26d1b7d5b78fc042b3bc2fdc6ff170c13` |
| `index.0e8706.js` | `dec161e29503471220530015c0ebbec4e095bd318080d4229b98da9186197ac3` |

Правила применяются к D9 с тем же интерфейсом и структурой конфигурации,
независимо от даты прошивки. Неизвестный интерфейс требует отдельной проверки.
Low и HEM в проверенном интерфейсе отсутствуют и не разрешаются.
Команды на других D9 в рамках этой проверки не отправлялись.

Модульные тесты в `tests/test_stock_compatibility.py` проверяют сохранение
настроек и пустого уровня частоты, подсветку, перезагрузку и блокировку
записи при отсутствии обязательного поля конфигурации.
Общий прогон: 184 теста успешно. EXE не пересобирался.
