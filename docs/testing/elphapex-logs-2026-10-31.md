## Основание для реализации

Имена компонентов взяты из JavaScript основного интерфейса. Скрипты изучались
как текст, без исполнения. Оба компонента при открытии Log вызывают
`GET /cgi-bin/hlog.cgi` для текущего журнала. Найденные POST-запросы для счётчика
и выбора старых журналов не отправлялись.

Основной маршрут и его LuCI-вариант `GET /cgi-bin/luci/hlog.cgi` проверены
чтением на обоих ASIC. Оба возвращают текст, содержащий события майнера,
без передачи учётных данных. Основная HTML-страница, напротив, требует Basic.

После исследования выполнена отдельная проверка через
`miner_scanner.device_logs.read_device_log` с пустым набором профилей доступа.
На каждый ASIC отправлен один GET-запрос к основному маршруту, без пароля.
Числа в таблице относятся к этой проверке; журнал продолжает дополняться,
поэтому размер может отличаться при следующем чтении.

Диагностические пакеты сформированы, наличие текста журнала и скрытие адреса
выбранного устройства проверены. Автоматическое скрытие не гарантирует удаления
любых персональных данных: перед передачей нужен просмотр очищенного пакета.
Исходные журналы в репозиторий не сохранялись.

Последующее чтение статистики показало положительный хешрейт плат:
около 11,71 GH/s у DG1 и 14,32 GH/s у DG1+. Команды управления, очистка журналов
и изменения настроек не выполнялись.

## Границы поддержки

- В карточке доступен только журнал **Майнер**; отдельный системный журнал
  не подтверждён.
- Способ чтения выбирается по профилю `elphapex.luci`, без запрета по дате
  прошивки. Аппаратная проверка относится к двум указанным версиям.
- На неизвестной версии отсутствие маршрута, отказ в доступе, ошибочный
  формат или тайм-аут показываются отдельно от успешного пустого журнала.
- Резервный LuCI-маршрут используется только после 404/405/501. HTML, JSON-ошибка,
  401/403, перенаправление и ошибка сервера не служат поводом для смены пути.
- После 401/403 могут использоваться только явно настроенные профили Elphapex.
  Для чтения на проверенных устройствах они не потребовались.
- Общий срок операции — 20 секунд, предел текста — 2 МиБ. Доступны отмена,
  поиск, копирование и очищенный экспорт через существующую карточку.
- Подменные проверки маршрутов, доступа, ограничений и отмены находятся в
  `tests/test_elphapex_device_logs.py`.
