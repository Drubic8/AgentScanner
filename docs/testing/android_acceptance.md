Для подтверждения команд используется существующая матрица испытаний ASIC;
до её заполнения правило не помечается `verified_commands`.

## Решение по прототипу

Выбран Kotlin + Compose и Chaquopy, чтобы сохранить единственный Python-каталог прошивок
и использовать нативные жизненный цикл, сеть и сохранение файлов Android.
Первый выпуск работает только при открытом приложении, minSdk 24, targetSdk 36,
архитектуры arm64-v8a/x86_64, распространение APK для испытаний через GitHub Actions.
Допуск к стабильному релизу требует проверки на физическом телефоне и ASIC,
постоянной release-подписи и отдельного решения о фоновом режиме.
