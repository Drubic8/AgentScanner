# Приёмка оборудования и диагностические данные

## Матрица совместимости

Шаблон Excel: `docs/testing/asic_acceptance.xlsx`. Одна строка — одна точная
модель, аппаратная ревизия и сборка прошивки. Семейство Stock/VNish недостаточно.
Стартовые строки — заготовки для заполнения, а не заявление о поддержке.
При новой прошивке копируйте строку и сбрасывайте результаты. Укажите версию
программы, дату, исполнителя и псевдоним устройства (например, device-001).

Статусы: **✓ Пройден**, **✗ Ошибка**, **Не проверено**, **Не поддерживается**.
Последний статус требует подтверждения документацией или проверкой возможностей;
таймаут и отказ авторизации не означают отсутствие функции.
На листе «Журнал» записывайте отдельные прогоны и имена файлов доказательств.
HTTP 200, ответ `accepted` или исчезновение устройства из сети сами по себе
не подтверждают выполнение команды.

Управляющие испытания выполняются вручную на выделенном тестовом ASIC в согласованное
окно: перезагрузка, сон, запуск и смена режима прерывают/меняют добычу.
Перед испытанием запишите исходный режим. После — восстановите его и проверьте хешрейт.
Не включайте неподтверждённые команды массово. Текущие профили не имеют аппаратно
подтверждённых `verified_commands`; таблица автоматически их не разблокирует.

## Сбор из терминала VS Code

VS Code должен работать на ПК с сетевым доступом к ASIC. Сам редактор доступ
не предоставляет. Откройте терминал PowerShell в корне проекта. Используйте
Python с установленными зависимостями проекта. В этой рабочей папке он расположен
в `.venv-build\Scripts\python.exe`; на другом ПК путь может отличаться.

Один опрос (подставьте настоящий IP и новое имя ZIP):

```powershell
.\.venv-build\Scripts\python.exe -m miner_scanner.diagnostics 192.168.1.10 --output diagnostics\z15-first.zip
```

Если API требует учётные данные:

```powershell
.\.venv-build\Scripts\python.exe -m miner_scanner.diagnostics 192.168.1.10 --username root --ask-password --auth digest --output diagnostics\z15-auth.zip
```

Пароль вводится скрыто, не передавайте его аргументом командной строки. Выбор
Basic/Digest должен соответствовать API прошивки; этот сборщик не реализует
отдельный вход по токену VNish. При закрытом API архив покажет ошибки авторизации,
но не сможет получить закрытые данные.

Повторный опрос диапазона — 120 циклов, пауза 30 секунд **после завершения** каждого
цикла, то есть немного больше часа:

```powershell
.\.venv-build\Scripts\python.exe -m miner_scanner.diagnostics 192.168.1.10-20 --workers 8 --samples 120 --interval 30 --output diagnostics\poll-1h.zip
```

Для суточного испытания используйте `--samples 2880 --interval 30`, записывая
фактическую длительность. Ctrl+C завершает активные запросы и сохраняет частичный
архив. Уже существующий ZIP не перезаписывается. Код выхода 2 означает отсутствие
свежих записей устройств; архив с ошибками всё равно сохраняется.

## Содержание архива

- `manifest.json`: число адресов/циклов/записей, настройки, время начала/окончания,
  отмена и количество событий, отброшенных при достижении лимита 32 МиБ.
- `events.jsonl`: псевдоним устройства, разрешённый запрос чтения, длительность,
  класс ошибки, обезличенный JSON ответа и разобранная запись устройства.

Сборщик не вызывает команды управления, не сохраняет SQLite-паспорта на диск,
не пишет пароль, HTTP-заголовки, HTML и произвольные текстовые ответы. Из JSON
удаляются чувствительные поля и неизвестные строки; сохраняются числовые показатели
и разрешённые поля модели/версии. Это сознательно неполная копия API.
Нестандартные поля прошивок могут требовать дополнительной ручной очистки: перед
передачей распакуйте архив и проверьте содержимое. Не отправляйте вместо него
credentials.json, сетевые дампы или необработанные конфиги майнеров.

Передайте ZIP, точную модель/версию прошивки и описание ожидаемого/фактического
результата. Для ошибки команды приложите её статус из GUI и результат повторного
чтения/визуальной проверки. В той же рабочей папке агент сможет прочитать архив
по указанному пути; с другого ПК приложите ZIP к сообщению. Диагностическая команда
добавлена в исходники; опубликованный EXE 2.0.0 её не содержит.

## Скриншот и PDF

Кнопка скриншота копирует видимую правую панель (итоги + таблица) в буфер обмена.
Вставьте Ctrl+V в Paint/сообщение и сохраните PNG. Строки и столбцы за пределами
видимой области в изображение не попадают. В исходниках исправлен захват только
таблицы; опубликованному EXE требуется новая сборка для этого исправления.

PDF экспортирует результаты сканирования в папку из настроек PDF (по умолчанию
`%LOCALAPPDATA%\ASICMonitor\export_pdf`). Он использует данные сканирования,
а не изображение таблицы; текстовый фильтр GUI не ограничивает состав отчёта.
Колонки и оформление задаются в настройках. PDF и обычные CSV/XLSX отчёты
не обезличиваются и могут содержать IP и данные пулов.
