# Avalon 1346-110: чтение пулов без изменения настроек, 09.11.2026

Проверен один согласованный экземпляр, псевдоним `pool-avalon-001`.
Чтение TCP API успешно; получить закрытую веб-форму настроек не удалось.
Ветка изменения пулов для этого интерфейса в программе пока не реализована.
Это не доказательство отсутствия такой функции у оборудования.

## Что прочитано

Однократно выполнены TCP 4028 `version` и `pools` с пустым `parameter`.
В ответе `POOLS` три объекта; `POOL` и `Priority` имеют тип integer,
`URL` и `User` — string. Есть поля статистики и состояния, но поля пароля
нет ни в одном из трёх объектов. Это рабочая телеметрия пулов;
чтение полного сохранённого трёхслотового конфига с паролями не доказано.

HTTP 80 `GET /` возвращает HTTP 200 и форму входа размером 14 727 байт:
`POST /login.cgi`, кодирование `application/x-www-form-urlencoded`,
поля `username` (text) и `passwd` (password), без начальных value.
Статический обработчик `checkLogin` проверяет непустые поля и вызывает
`loginform.submit()`; преобразование пароля, challenge или CSRF-поле
в этой форме не обнаружены. JavaScript на устройстве не исполнялся.

Выполнены две отдельные попытки входа с одним и тем же первым существующим
профилем доступа. Первая закончилась `ConnectionError` до HTTP-ответа.
После отдельного чтения механики формы выполнена одна попытка с заголовками
того же origin/referer и закрытием соединения; она также закончилась цепочкой
`ConnectionError → ProtocolError → RemoteDisconnected`, без HTTP-ответа.
Это не установленный отказ в пароле. Другие профили, пароли и обходы не пробовались.
Закрытая форма пулов и её локальные скрипты не получены.

## Что не выполнялось и что остаётся неизвестным

Суммарно отправлены два TCP-запроса чтения, четыре `GET /`
и два POST исключительно в наблюдавшуюся форму входа.
POST сохранения настроек, команды управления, TCP 8889, перезапуск
и изменение пулов/worker/паролей не выполнялись. Cookies оставались в памяти.

Пока неизвестны точные поля и тело записи пулов, способ сохранения
неизменённых полей и паролей, ответ об успешном сохранении, необходимость
применения/перезапуска и чтение сохранённого конфига после записи.
Проверка записи на оборудовании не проводилась. Одного TCP `pools`
недостаточно для безопасного переноса контракта сохранения.
