# Перезагрузка Antminer Z11, Z15 и Z15 Pro

## Причина блокировки

Эти модели отсутствовали в списке моделей, для которых определяется совместимость
Stock API. Для старых Z11/Z15 также не распознавалась отдельная страница
`/reboot.html`: прежняя проверка искала только современный `index.*.js`.
Поэтому команда блокировалась локально до отправки ASIC.

## Проверка интерфейсов 01.10.2026

| Устройство | Модель из API | Источник команды | Совместимость reboot |
| --- | --- | --- | --- |
| 10.33.6.12 | Antminer Z15 Pro | `/js/index.16ab47.js` | Подтверждена по коду интерфейса |
| 10.33.6.15 | Antminer Z15 | `/reboot.html`, вариант 2013–2022 | Подтверждена по коду интерфейса |
| 10.33.6.16 | Antminer Z11 | `/reboot.html`, вариант 2013–2018 | Подтверждена по коду интерфейса |

Во всех трёх случаях кнопка перезагрузки вызывает `GET /cgi-bin/reboot.cgi`
без параметров. Используется существующий исполнитель команды Antminer.

Проверенные SHA-256 содержимого:

- `index.16ab47.js`: `fe388e83f2ed6f7dad726b2468c335d88c0ec1378a8d2cd2e5d3f2cfa59313c4`;
- `reboot.html` Z15: `712fbee71caa8c94ccb51b148ea61ce4323530f400af61208048d66b867ff8cb`;
- `reboot.html` Z11: `8c6c727e12aa256640a78aea2203707fe0deb727297b01d701a36b5962700e95`.

Хеши внесены в `miner_scanner/profiles/stock_interfaces.json`.
Дата прошивки не участвует в разрешении этой команды. Изменённый, неизвестный
интерфейс требует отдельной проверки. Для старых страниц подтверждена только
перезагрузка; сон и подсветка этим правилом не разрешаются.

Сканирование читает статические страницы и не вызывает командные CGI.
Перед отправкой команды интерфейс проверяется заново. Повтор одной команды
с тем же идентификатором не вызывает повторную перезагрузку.

## Что проверено

- Настоящее сканирование всех трёх адресов обновлённым `ScannerService`:
  свежие данные, правильные модели, `reboot=supported`.
- Модульные тесты: современные/старые интерфейсы, обе версии старой страницы,
  неизвестная или изменённая страница, повторная проверка и отсутствие
  повторной отправки команды.
- Аппаратная перезагрузка в этой проверке **не выполнялась**. После отправки
  GUI может показать `unconfirmed`: команда принята API, но завершение
  перезагрузки ещё не проверено. Это отличается от прежнего `unsupported`.

Для пользовательской проверки перезапустите `gemini_gui.py`, заново
просканируйте адрес и отправьте перезагрузку одному устройству. Дождитесь
возвращения устройства в сеть и проверьте сброс времени работы.
Новый EXE в рамках исправления не собирался.
