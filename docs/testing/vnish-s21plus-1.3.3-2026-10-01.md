# Antminer S21+ / VNish 1.3.3: подсветка

Проверено 01.10.2026 на `10.33.219.4`.
`/api/v1/info` определяет VNish 1.3.3, сборка от 22.05.2026,
модель Antminer S21+. HTML содержит бренд AnthillOS, но для определения
прошивки используется структурированный ответ API.

## Причина и исправление

Общий профиль VNish блокировал непроверенные команды. Старый исполнитель
также использовал `POST /api/v1/find-miner` с полем `on`.
Веб-интерфейс этой сборки использует другую команду:

```text
POST /api/v1/unlock       {"pw": "<пароль профиля>"}
POST /api/v1/locate-miner {"is_enabled": true/false}
GET  /api/v1/status
```

После входа запись и проверка используют один Bearer-токен.
Результат подтверждается только если `find_miner` содержит ожидаемое
логическое значение. Ответ HTTP 200 сам по себе недостаточен.

Контракт проверен по JavaScript интерфейса `/assets/index-CdF1v03q.js`
и встроенной документации `/docs/api-doc.json`. В OpenAPI присутствует
`POST /locate-miner`, но отсутствует описание тела этого запроса;
поле `is_enabled` подтверждено кодом интерфейса и проверкой на устройстве.
SHA-256 JavaScript:
`3e9a7fd2863b9ae31a24291dae514e78b9a7cc23dd3b14703010eec606a1c92c`.

`miner_scanner/vnish_compatibility.py` читает статическую страницу, проверенный
скрипт и статус; JavaScript не исполняется. Правило из
`miner_scanner/profiles/vnish_interfaces.json` применяется к тому же интерфейсу
API независимо от модели и даты прошивки. Неизвестный интерфейс требует
отдельной проверки. При обычном опросе сведения кешируются; перед командой
интерфейс проверяется заново.

## Аппаратный результат

| Действие | Результат |
| --- | --- |
| Включить подсветку | API принял команду; прочитан `find_miner=true` |
| Выключить подсветку | API принял команду; прочитан `find_miner=false` |

Визуальное подтверждение индикатора оператором не получено.
Перезагрузка и смена режима в рамках этой проверки не выполнялись и
не стали автоматически поддерживаемыми командами этого контракта.

`tests/test_vnish_compatibility.py` проверяет выполнение через ScannerService,
Bearer-токен, чтение ожидаемого состояния, повторную проверку интерфейса,
блокировку изменённого интерфейса, кеширование, запрет произвольных ссылок
и отсутствие повторной записи команды с тем же идентификатором.
Старый формат `find-miner/on` сохранён в исполнителе для прежних правил.
EXE не пересобирался; для проверки перезапустите GUI из исходников.
