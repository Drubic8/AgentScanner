# Antminer L9 Stock — пробуждение, 28.09.2026

Устройство `10.33.222.16`, модель `Antminer L9`, системная сборка
`Mon Feb 10 10:01:06 CST 2025`, API `3.1`, Miner `86.48-2.0.0`.

## Контракт API

Изучен веб-интерфейс самого устройства: `/miner.html` и `/js/miner.0ef2dc.js`.
Он читает `/cgi-bin/get_miner_conf.cgi` и отправляет JSON через
`POST /cgi-bin/set_miner_conf.cgi`:

- `miner-mode`: `0` для работы, `1` для сна;
- `freq-level`: исходное значение `bitmain-freq-level`;
- `pools`, `bitmain-fan-ctrl`, `bitmain-fan-pwm`: текущие значения из конфигурации.

В ответе чтения режим называется `bitmain-work-mode`. Проверять записанный
`miner-mode` в этом ответе неправильно. Добавлено декларативное соответствие
полей `config_fields`, без догадок о названиях или частоте.

## Дополнение: подсветка L9 `10.33.222.11`

Модель, системная сборка и API совпали с профилем выше. Веб-интерфейс
`/js/index.d5a821.js` отправляет `POST /cgi-bin/blink.cgi` с JSON
`{"blink": true}` или `{"blink": false}`, затем читает
`GET /cgi-bin/get_blink_status.cgi`.

Фактические ответы:

| Действие | Ответ записи | Последующее чтение | Результат исправленного обработчика |
|---|---|---|---|
| Включить | HTTP 200, `{"code":"B000"}` | `{"blink":true}` | `succeeded` |
| Выключить | HTTP 200, `{"code":"B100"}` | `{"blink":false}` | `succeeded` |

Код `B100` разрешён только в правиле выключения подсветки этого профиля.
Общий список успешных кодов не расширялся. Успех требует обратного чтения
булевого значения; отсутствие поля, строка `"false"` и число `0` не заменяют
настоящий `false`. Включение/выключение проверены через обычный диспетчер без
экспериментального флага. В конце индикатор выключен по API.

Визуальное подтверждение на корпусе пользователем пока не получено;
в матрице зафиксировано подтверждение API, без отметки полной визуальной приёмки.
Регрессии покрывают оба действия, код B100, отсутствие повторной отправки,
строгий тип состояния и запрет на другой версии прошивки.
