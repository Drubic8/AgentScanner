# Goldshell HS5 / Stock 2.2.1: сканирование, 13.10.2026

Выполнены только запросы чтения к одному HS5 пользователя. Публичные GET-запросы
MCB не потребовали пароля. Разблокировка, изменение настроек, подсветка,
переключение алгоритма и перезагрузка не выполнялись.

## Источники

| Запрос GET | Назначение |
| --- | --- |
| `/mcb/status` | Модель Goldshell-HS5, firmware 2.2.1 |
| `/mcb/cgminer?cgminercmd=devs` | Показатели четырёх плат, время работы и датчики |
| `/mcb/algosetting` | Названия алгоритмов и выбранный `algo_select` |
| `/mcb/pools` | Массив пулов, активный пул и работник |
| `/mcb/setting` | Текущее состояние `ledcontrol` |

Распознавание использует структуру `/mcb/status`, модель с префиксом Goldshell
и строку прошивки. Заголовок страницы `cloud-box` сам по себе недостаточен.

## Единицы и выбранный алгоритм

Статически изученный код веб-интерфейса этого устройства
`/js/app.c0c55709.js` содержит `hashrateConversion`, который умножает исходные
счётчики на 1e6. Значения `hashrate` и `av_hashrate` каждой платы поэтому
интерпретируются как MH/s, суммируются и отображаются в GH/s. Код устройства
не исполнялся. При отсутствующем показателе одной из плат неполная сумма не
выдаётся за измеренный хешрейт всего ASIC.

В момент проверки выбран `blake2b(SC)` — в программе **Blake2B-Sia**.
Второй предлагаемый прошивкой вариант `blake2bsha3(HNS)` отображается как
**Blake2B+SHA3**. Выбор сопоставляется по ID и названию из текущего ответа API,
а не по фиксированным ID или по модели. Настройка алгоритма читается при каждом
опросе. Если прочитать её не удалось, алгоритм неизвестен.

Возможность переключать HNS/SC для HS5 подтверждена в
[официальной инструкции Goldshell](https://goldshellhelp.zendesk.com/hc/en-us/articles/16822039169433-Guidelines-for-HNS-SC-and-KDA-SC-Switching).
Обозначение SC отделено от Blake2B Antminer A3: разные семейства алгоритмов
не должны объединяться в общую сумму без проверки совместимости.

## Датчики и состояние

MCB повторяет одинаковый набор четырёх вентиляторов в каждой записи платы.
В программе показывается один физический набор, как в веб-интерфейсе,
а не шестнадцать значений. Нулевые RPM сохраняются. Температуры обеих точек
каждой платы читаются отдельно.

Работа подтверждается ответом `status=2`, состояниями плат `minerstatus=0`
и положительным текущим хешрейтом. Нулевой хешрейт не означает сон.
При ошибках плат указывается их ID и код. Состояние LED читается из
`ledcontrol`; доступные команды управления пока не заявлены.

Обезличенный снимок: `tests/fixtures/goldshell_hs5_mcb.json`. В исходном снимке
5082.35 GH/s текущего и 5344.04 GH/s среднего хешрейта; при последующих опросах
значения менялись. Адрес, MAC, пулы и учётные данные в снимок не включены.

## Использование и проверки

В GUI включите «Остальные · Avalon, iPollo, Jasminer, Goldshell, Generic».
Тесты `test_goldshell.py`, проверка JSON-массива в `test_transports.py` и
интеграционная проверка GUI используют подмены и не обращаются к сети.
Полный опрос реального HS5 проверен через транспорт, ограниченный списком
разрешённых запросов чтения.

Изменены исходники общего сканера и фильтр GUI. Новые EXE/APK не собирались,
агент и сервер не обновлялись. Наличие профиля MCB не означает проверку всех
моделей Goldshell или всех версий прошивки.
