# Расшифровки ошибок WhatsMiner

Источник: [WhatsMinerTool Error Code Description, 03.06.2026](../Whatsminer%20demo/Error%20Code%20Description20260603_1780474268305.pdf), 4 страницы.

В `miner_scanner/whatsminer_errors.py` перенесены 159 записей справочника:
точные десятичные и шестнадцатеричные коды, шаблоны плат и чипов,
диапазон 280–299. Число включает шаблоны, а не все их возможные значения.
Расшифровки переведены на русский; для каждой указана страница источника.

В GUI наведите курсор на ячейку столбца «Ошибки». Подсказка показывает:

- код и описание;
- сообщение устройства `reason`, если API его передал;
- название, дату и страницу справочника.

Несколько ошибок разделяются пустой строкой. Неизвестный код сохраняется
с пометкой об отсутствии расшифровки. Нулевые коды и поля времени не считаются
ошибками. Текст ASIC отображается буквально, включая угловые скобки.

## Исправления относительно старого словаря

| Код | Расшифровка из документа |
| --- | --- |
| 2310, 2320 | Низкий хешрейт |
| 233–235 | Температурная защита выходной части БП |
| 249 | Защита от повышенного входного напряжения БП |
| 32X | Ошибка чтения температуры платы |
| 51X | Несовместимый тип платы |
| 53X | Плата не обнаружена |
| 800–802 | Ошибки контрольных сумм ПО |
| 54XBBB | Температурная защита чипа |

Точные коды 309, 326, 329 и 5079 имеют приоритет над шаблонами.
Индексы `X` и `BBB` показываются в нумерации устройства. Значению `999`
не присваивается недокументированное значение «все чипы».

Уровень тяжести и рекомендации по ремонту из PDF пока не выводятся:
описание зарегистрированного события само по себе не подтверждает диагноз.
Расшифровка используется только для WhatsMiner; справочники других
производителей не подменяются.

## Проверка

`tests/test_whatsminer_errors.py` проверяет исправленные значения, приоритет
точных кодов, шаблоны, неизвестные коды и форматы ответов RPC.
`tests/test_gui.py` проверяет вывод подсказки в таблице, переносы строк и
буквальное отображение HTML из сообщения устройства. Проверки локальные,
без отправки команд оборудованию.

Справочник встроен в Python-модуль. PDF и библиотека для его чтения
не нужны при запуске программы. Чтобы увидеть изменение сейчас, перезапустите
`gemini_gui.py` из обновлённых исходников. В ранее собранном EXE останется
старая реализация до следующей сборки.
