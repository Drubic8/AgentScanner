# Подсветка Elphapex DG1, Antminer KS5 и VNish — 02.10.2026

Пользователь сообщил отказ `unsupported` в опубликованном Windows EXE 2.1.0.
Исправления проверены из текущих исходников на трёх указанных им устройствах.
Идентификаторы, IP, пулы, пароли и токены в этот журнал не включены.

| Устройство | Проверенный интерфейс | Включение | Выключение |
| --- | --- | --- | --- |
| Elphapex DG1, DG1_SW_V1.0.4 | LuCI API 1.0.0 | `succeeded`, `blink=true` | `succeeded`, `blink=false` |
| Antminer KS5, 28.08.2024 | Stock, index.084178.js | `succeeded`, `blink=true` | `succeeded`, `blink=false` |
| Antminer L9, VNish 1.2.6 | index-IOfCXv6T.js, find-miner | `succeeded`, `find_miner=true` | `succeeded`, `find_miner=false` |

Перед записью диспетчер повторно определял устройство и совместимость. После
записи выполнялось чтение целевого состояния. Исходное состояние подсветки
восстановлено на всех трёх ASIC. Это подтверждение API; визуальное подтверждение
индикаторов в этом прогоне не получено. Другие команды в этот прогон не входили.

## Причины отказов и изменения

### Elphapex

Обработчик `ftm_ledtest.cgi` уже существовал и ранее прошёл аппаратную проверку
[DG1](elphapex-dg1-2026-09-28.md), но общий диспетчер не выдавал ему допуск.
Сканер теперь сопоставляет модель DG1, объявленную версию LuCI API 1.0.0 и
булевый ответ `/cgi-bin/luci/get_blink_status.cgi` с локальным каталогом
`profiles/elphapex_interfaces.json`. Разрешаются только две команды подсветки.

Для этого API не требуется загрузка веб-страницы, защищённой Basic-авторизацией.
Дата прошивки не служит селектором контракта. Другие модели, версии API и
небулевое поле статуса не получают этот допуск. Разрешение подсветки не означает
поддержку режимов мощности или аппаратную проверку всех сборок семейства.

### KS5

Изученный общий интерфейс Bitmain уже был в каталоге, но проверка моделей
исключала KS5. Общие команды страницы теперь распознаются для Stock Bitmain
по изученному интерфейсу. Режимы мощности по-прежнему требуют отдельного
соответствия модели и схемы конфигурации в каталоге; KS5 их автоматически
не получает. Перезагрузка распознаётся по общему интерфейсу, но в этом прогоне
на KS5 не выполнялась.

### VNish

Скрипт интерфейса VNish 1.2.6 занимает 1 420 958 байт и превышал лимит API
в 1 МиБ. Для чтения локальных скриптов добавлен отдельный `max_asset_bytes`
(2 МиБ по умолчанию), с прежними ограничениями времени и отменой. JSON/TCP
сохраняют лимит `max_response_bytes` в 1 МиБ.

Изученный старый интерфейс отправляет `POST /api/v1/find-miner` с `{"on": true}`
или `false`; новый — `/api/v1/locate-miner` с `is_enabled`. Каталог
`profiles/vnish_interfaces.json` различает их по SHA-256. Команды задают состояние,
не переключают его вслепую. Обе используют существующие unlock/Bearer и
проверку `find_miner`. Локальный OpenAPI этой версии не описывает тело запроса
find-miner; формат подтверждён исходником интерфейса и фактическим выполнением.

## Регрессионные проверки

Автотесты проходят через общий диспетчер и проверяют оба интерфейса VNish,
повторное задание того же состояния, DG1 без HTTP-авторизации страницы, отсутствие
допуска неизвестному API/модели, изменение схемы перед записью, сохранение
настроек майнинга, чтение результата и отсутствие повторной записи одной команды.
Отдельные тесты транспорта проверяют превышение обоих лимитов и сохранение
ограничения JSON/TCP после загрузки большого скрипта.

Полный локальный набор: **252 теста успешно**. При обычном времени опроса
по умолчанию (15 секунд) все три устройства также определились с доступной
подсветкой и свежей телеметрией: KS5 за 0,85 с, VNish за 1,37 с, DG1 за 3,06 с.
Это наблюдение данного прогона, не гарантия скорости для других сетей.

Исходники общие для Windows, Android и агента. Для проверки собран отдельный
локальный `dist/control-compatibility/ASIC_Monitor-led-fix-test.exe`, с версией
2.1.0 в окне и отдельным SHA256SUMS.txt. Включение исправленных модулей и каталогов
в EXE проверено. Запуск и экспорт скриншота, CSV, XLSX и PDF прошли проверку
на демонстрационных данных без сети.

Опубликованный релиз 2.1.0 содержит прежний код. Его тег и файлы этим тестом
не заменяются. Android APK этим прогоном не пересобирался.
