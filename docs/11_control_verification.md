# Control Verification

Как проверять, что команда реально сработала. "HTTP 200 means success" - это плохой критерий для многих прошивок, особенно Bitmain CGI.

## Основной алгоритм для CGI-конфигов (Bitmain)

Многие прошивки возвращают `HTTP 200 OK` даже если они не приняли конфигурацию (например, если передать строку вместо числа, или пропустить обязательное поле).

**Правильная верификация (Verification Flow):**
1. Отправить конфигурацию (`POST /cgi-bin/set_miner_conf.cgi`).
2. Дождаться ответа. Если ответ не 200 - сразу считать ошибкой.
3. Если ответ 200, сделать паузу (1-2 секунды).
4. Запросить текущий конфиг заново (`GET /cgi-bin/get_miner_conf.cgi`).
5. Извлечь ключевое поле, которое мы меняли (например, `miner-mode` или `bitmain-work-mode`).
6. Сравнить текущее значение с ожидаемым (Expected Mode).
7. Если не совпадает - повторить попытку (до 3 раз).

## Правила для HTTP 200 / 404 / Empty Body

- **HTTP 200 + Ожидаемый конфиг:** Успех.
- **HTTP 200 + Старый конфиг:** Устройство проигнорировало payload (неверные типы данных, недостающие поля). Требуется Fallback или ручное исправление типа значения (normalize payload).
- **HTTP 401:** Ошибка авторизации. Некоторые асики принимают Basic Auth, некоторые Digest Auth. В случае 401 на Digest, делаем Fallback на Basic Auth.
- **Timeout:** Для команд типа Reboot (перезагрузка) таймаут означает, что асик мгновенно ушел в перезагрузку и не успел закрыть соединение. В этом случае таймаут считается УСПЕХОМ.
- **Empty Body / 404:** Некоторые старые прошивки (Legacy VNish) могут возвращать 404 на новые API эндпоинты. В этом случае срабатывает Fallback logic на старые пути (например, `/api/v1/system/blink` вместо `/api/v1/find-miner`).

## Fallback Logic

1. **Auth Fallback:** Сначала Digest, при неудаче (401) - Basic.
2. **Payload Fallback:** Если профиль не определен точно, отправляем все ключи (`bitmain-work-mode` + `miner-mode`), чтобы попытаться "угадать" нужный формат.
3. **Endpoint Fallback:** Если новый эндпоинт отдает 404, пробуем альтернативный (старый) эндпоинт.
