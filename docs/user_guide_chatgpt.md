# Подключение аккаунта ChatGPT

Эта инструкция относится к текущим исходникам ASIC Monitor после выпуска
`v2.6.0`. В опубликованном Windows EXE 2.6.0 и Android APK 2.5.0 такого входа нет.
Используйте [запуск из исходников](../README.md#запуск-из-исходников) с
зависимостями `desktop`, включая компоненты проверки безопасного входа.

Программа подключает ваш аккаунт через официальный **Sign in with ChatGPT**.
Для подходящих аккаунтов запросы могут использовать план ChatGPT или доступные
кредиты. Нужны разрешение этого механизма для аккаунта и поддерживаемый регион;
наличие подписки само по себе не гарантирует доступ. OpenAI описывает этот путь
для подходящих открытых локальных приложений и аккаунтов Plus/Pro.
[Условия подключения](https://developers.openai.com/siwc/quickstart),
[поддерживаемые регионы API](https://developers.openai.com/api/docs/supported-countries).

API-ключ OpenAI для этого варианта не нужен. Пароль и подтверждение входа
вводятся только в браузере на странице OpenAI. Не присылайте пароли, токены
или адрес callback из браузера в чат.

## Подключить аккаунт

1. Откройте **Настройки → ИИ и диагностика** и выберите провайдер **Аккаунт ChatGPT**.
2. Нажмите **Continue with ChatGPT**. Откроется системный браузер с авторизацией
   OpenAI. Статус входа показывается рядом с кнопкой. Если браузер не появился,
   нажмите **Открыть окно входа**, пока попытка входа активна.
3. Войдите в нужный аккаунт и проверьте разрешение использовать план для ASIC
   Monitor. После подтверждения браузер вернётся на временную локальную страницу.
4. Вернитесь в программу. Проверьте, какой аккаунт выбран и разрешено ли
   использование плана. Подтвердите информационное окно об учёте запросов.
5. Нажмите **Загрузить модели аккаунта**, выберите доступную модель и сохраните
   настройки.

Первый вход, выбор другого аккаунта и выход сохраняются сразу. Кнопка
**Отмена** в общих настройках не отменяет уже выполненный вход или выход.
Параметры провайдера и модели применяются после **Сохранить**.

Модели берутся из каталога вашего аккаунта. Не нужно угадывать
идентификатор модели или подставлять его из другого сервиса. После смены
аккаунта загрузите список заново.

**Проверить подключение** отправляет короткий искусственный запрос без логов и
показаний ASIC. Он использует лимит вашего плана. Загрузка названий моделей не
выполняет диагностический запрос.

Время ожидания настраивается от 5 до 120 секунд, по умолчанию 45 секунд.
Лимит токенов из настроек Яндекса для ChatGPT не применяется и не отправляется.
Программа ограничивает размер полученного ответа локально; это не задаёт
стоимость или расход лимита на стороне OpenAI. Для проверки расхода используйте
**Управление использованием**.

## Проанализировать ASIC

1. Выполните сканирование и откройте **Карточку устройства**.
2. Получите поддерживаемый лог или откройте сохранённый текстовый файл.
3. На вкладке **ИИ-анализ** проверьте активный провайдер, аккаунт, модель и
   **Данные для отправки**. Известные идентификаторы скрываются, но
   автоматическая очистка может пропустить произвольные личные сведения.
4. Установите подтверждение отправки этого запроса и нажмите
   **Проанализировать**.
5. После завершения изучите заключение и ссылки на показания/строки.
   Заключение можно скопировать или сохранить в TXT.

Запрос передаёт выбранные очищенные данные в OpenAI. Он не даёт модели доступ
к вашей сети или перепискам ChatGPT. ИИ не отправляет команды перезагрузки,
сна или настройки ASIC. Вывод относится к снимку карточки; импорт и сокращение
лога указываются отдельно.

Обычное сканирование не запускает ИИ. Каждый повторный запрос требует нового
подтверждения; программа не повторяет его автоматически и не переключается
на API-ключ или другого провайдера при отказе плана.

## Другой аккаунт и выход

Для новой регистрации нажмите **Другой аккаунт…**. Для уже сохранённой —
выберите её в списке. Разные регистрации могут иметь одинаковый email;
ориентируйтесь также на различающую подпись записи. Данные других регистраций
при переключении сохраняются.

Кнопка **Выйти из ChatGPT** завершает локальную сессию выбранной регистрации и
пытается отозвать её на сервере. Если удаление локальных токенов выполнено, но
отзыв не подтверждён, программа сообщает об этом. Проверьте доступ приложения
в настройках ChatGPT. Выход не удаляет сам аккаунт ChatGPT.

Сеансы хранятся отдельно от обычных настроек в зашифрованном
`chatgpt_credentials.dat`, для текущего пользователя Windows. Эти файлы и
`.chatgpt-host.json` не нужно переносить между компьютерами: на каждом ПК
выполните отдельный вход. Не публикуйте файлы сеансов, их резервные копии или
авторизационные ссылки.

## Если вход или анализ не сработал

| Сообщение или ситуация | Следующее действие |
| --- | --- |
| Требуется вход | Нажмите Continue with ChatGPT и завершите авторизацию |
| Нет разрешения использовать план | Повторите вход и проверьте выданное разрешение |
| Механизм недоступен аккаунту | Проверьте условия OpenAI для аккаунта и рабочего пространства; повтор того же запроса не изменит ограничение |
| Запрос запрещён | Проверьте разрешения рабочего пространства и поддерживаемый регион |
| Достигнут лимит плана | Проверьте использование и доступ ASIC Monitor в настройках ChatGPT |
| Модель недоступна | Повторно загрузите модели выбранного аккаунта |
| Не удалось открыть браузер | Нажмите «Открыть окно входа». Если не помогло, проверьте браузер по умолчанию в Windows; после отмены или истечения времени начните новый вход |
| Не установлены компоненты входа | Запустите программу из окружения с зависимостями `desktop`, включая `PyJWT[crypto]`; после установки полностью перезапустите программу |
| Время ожидания истекло | Проверьте соединение; повторный запрос запускается только вручную |
| Ответ не принят | Посмотрите указанную причину и этап: незавершённый поток, отказ модели, формат JSON или ссылка на отсутствующие данные. Старое заключение не выдаётся за новое; новый запрос запускается только с вашим подтверждением |
| Отклонены параметры запроса | Скопируйте показанные рядом HTTP-статус, код, имя параметра и request ID для разбора ошибки. Повторный вход обычно не исправляет формат запроса |

Уже выполненный вход в ChatGPT в браузере не подключает ASIC Monitor
автоматически: разрешение для программы выдаётся отдельно. До открытия
браузера программа не обращается к OpenAI по сети. После возврата из браузера
она проверяет авторизацию; отсутствие доступа Python к OpenAI может помешать
этому этапу, даже если сам браузер работает.

При отмене уже принятый запрос может учитываться в плане. Системное
DNS-разрешение способно задержать отмену; программа ожидает завершения фоновой
операции перед закрытием окна.

При первом запуске начните с проверки подключения и одного очищенного
демонстрационного лога. Подробности проверок описаны в
[документе для разработчиков](development/chatgpt_sign_in.md#проверка-и-запуск-из-исходников).
