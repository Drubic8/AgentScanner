# Руководство пользователя

## Установка и обновление

Скачайте `ASIC_Monitor.exe` из [последнего релиза](https://github.com/Drubic8/AgentScanner/releases/latest). Это переносимая Windows x64 программа: отдельная установка Python не нужна.

Для обновления закройте старую программу и замените EXE. Сети и настройки находятся в `%LOCALAPPDATA%\ASICMonitor`, отдельно от EXE. При первом запуске программа также умеет читать старые настройки рядом с EXE. Не удаляйте каталог настроек при обновлении.

Рядом с EXE опубликован `SHA256SUMS.txt`: сравните его содержимое с результатом `Get-FileHash .\ASIC_Monitor.exe -Algorithm SHA256` после скачивания.

## Добавление и выбор сетей

Нажмите **Добавить сеть** и задайте понятное название, например «Площадка 1 · контейнер А».

В версии из исходников сети также можно организовать в дерево папок. Нажмите
**Папка**, например «Площадка 1» или «Перевод в сон». Новые сети и папки добавляются
в выбранную папку. Вложенность позволяет отдельно сгруппировать контейнеры и ряды.
Для существующих сетей используйте **Переместить в папку…**; можно выделить несколько
сетей через Shift / Ctrl. Старые сохранённые сети остаются в корне дерева.

Галочка папки включает или выключает все вложенные сети. Частичная галочка означает,
что выбрана только часть сетей. Пустая папка не создаёт целей для сканирования.
Это организация списка, а не расписание автоматического сна: команды выполняются
через меню **Управление** после сканирования.

| Запись | Что будет опрошено |
|---|---|
| `192.168.1.10` | Один IP |
| `192.168.1.10-50` | Адреса от .10 до .50 включительно |
| `192.168.1.10-192.168.2.20` | Полный интервал между двумя IP |
| `192.168.1.0/24` | Адреса .1–.254 |

Вводите диапазоны с новой строки или вставляйте список с запятыми/точкой с запятой. Редактор показывает ошибки и число уникальных IP. Повторы будут опрошены один раз. Лимит одного сканирования — 4096 уникальных адресов, включая все выбранные сети.

**Галочки определяют, какие сети сканировать.** Через **Shift** выделите диапазон строк, через **Ctrl** — отдельные строки, затем нажмите **Включить** или **Выключить**. Эти кнопки меняют галочки только у видимых выделенных сетей. **Изменить** и **Удалить** относятся к текущей строке; двойной щелчок открывает редактор. Удаление сохранённой сети не удаляет устройства или результаты из таблицы.

Поиск скрывает строки, но сохраняет галочки. **Все сети** включает или выключает весь список, в том числе скрытые поиском сети. Если все галочки сняты, сканирование не запускается. Выбор сохраняется при следующем запуске.

## Сканирование

1. Убедитесь, что компьютер имеет доступ к выбранной сети ASIC.
2. Стандартный доступ Antminer `root/root` и профили VNish `admin` / `root` загружаются автоматически. Для другого пароля откройте **Доступ к ASIC**, добавьте профиль с нужными IP/подсетями и сохраните. [Настройка профилей](access_profiles.md).
3. Выберите сети и нажмите **Начать сканирование**.
4. Результаты появляются по мере получения ответов. **Остановить** отменяет оставшуюся работу, уже полученные результаты сохраняются в таблице.

Если свежий опрос не удался, сохранённая запись из кэша не добавляется в таблицу, сводки и экспорт нового сканирования. IP и причина записываются в **Журнал**. Это не доказывает отключение питания: возможны также проблемы сети или доступа к API.

В карточках **Устройства**, **Модели**, **Хешрейт** подробности прокручиваются независимо. Наведите указатель на список и используйте колесо мыши либо полосу прокрутки.

В **Настройках программы** можно изменить производителей, время ожидания и число параллельных запросов. Если часть оборудования не отвечает, сначала проверьте доступ и API устройства, затем увеличьте время ожидания или уменьшите параллельность.

GUI запускает разовое сканирование. Перезапускайте его для получения новых данных; отдельная панель непрерывного опроса в этой версии ещё не реализована.

## Таблица и управление

Узкий столбец **LED** рядом с IP показывает состояние поискового индикатора:
заполненная жёлтая лампа — **включена**, контур лампы — **выключена**, `?` —
**неизвестно**. Полное описание доступно при наведении; в отчётах состояние
сохраняется текстом. Состояние считывается
из API при сканировании и после команды. Оно не обновляется непрерывно; после
изменения индикатора через другую программу повторите сканирование. Отсутствие
данных и устаревший снимок показываются как **Неизвестно**, а не как выключенная
подсветка. Столбец можно скрыть в настройках и включить в отчёты.

У VNish перед включением/выключением проверяется текущее состояние. Если оно уже
нужное, программа сообщает об этом и не отправляет повторный запрос: некоторые
прошивки 1.2.6/1.2.7 переключают индикатор даже при повторном `led_on`.

Для массового сна или пробуждения просканируйте выбранные сети, отметьте нужные
устройства и выберите **Управление → Сон (остановить майнинг)** либо
**Пробуждение (возобновить майнинг)**. В одном выборе могут быть разные модели и
прошивки: программа проверяет совместимость и отправляет команду отдельно каждому
IP. Результаты и отказы видны в журнале; отказ одного устройства не мешает остальным.

Подготовка и отправка выполняются параллельно для **32 устройств** по умолчанию.
Изменить число от 1 до 32 можно в **Настройки программы → Сканирование →
Параллельная отправка команд**. Подтверждение результата и обновление таблицы
выполняются в отдельных очередях: медленное чтение одного ASIC не занимает
место для отправки команды следующему. В очереди может находиться до 512 операций;
при большем выборе остальные ждут освобождения места.

Под таблицей отображаются три счётчика:

- **Очередь** — сколько устройств прошло этап подготовки и отправки, включая отказы.
- **Принято API** — сколько устройств положительно ответило на запись команды.
- **Подтверждено** — у скольких устройств нужное состояние прочитано из API.

Счётчики могут отличаться: например, VNish уже подсвечен и повторная запись не
нужна, либо команда принята, но результат ещё не подтверждён. Проверка не
повторяет команды записи. Новый запрос к тому же IP ждёт окончания предыдущего.

Это ускоряет массовое ручное управление, но не гарантирует одновременное
изменение состояния всех ASIC: перед записью остаётся проверка идентичности и
совместимости, а сон и запуск занимают разное время у разных прошивок.
Расписание вроде «сон в 08:50, пробуждение в 14:00» этим изменением в локальный
GUI не добавлено. Для него нужен постоянно работающий агент с предварительной
подготовкой списка устройств и отдельным учётом времени отправки и подтверждения.

Для стокового Antminer пробуждение через поддерживаемый контракт возвращает
режим Normal. Low и HEM выбираются отдельно в подменю **Режим мощности**, где
**Обычная мощность (Normal)** позволяет вернуться из специального режима.
Ранее выбранный Low/HEM при пробуждении автоматически не восстанавливается.
У проверенного Avalon 1346-110 пробуждение выполняется через перезагрузку:
программа показывает это в подтверждении. Рабочий хешрейт появляется после разгона.

Используйте поиск по IP, модели, прошивке, пулу или воркеру и фильтр состояния. **Выделить всё** выбирает только видимые строки. При скрытии строки фильтром выбор устройства снимается.

Недоступный показатель отображается как неизвестный, а не как ноль. Хешрейт с разными единицами суммируется отдельно.

Для команд отметьте устройства в таблице и откройте **Управление**. Для Stock L9, T21, S21 и поддержанных вариантов S21+ команды доступны при распознанном интерфейсе управления и подходящем формате конфигурации, даже если дата прошивки другая. LowPower и HEM доступны только в тех вариантах интерфейса, где они предусмотрены для устройства. Перед командой программа повторно проверяет совместимость. Другие устройства используют свои профили; неподтверждённое управление по умолчанию отключено. Экспериментальный доступ предназначен для испытания на выделенном ASIC и не включает режимы, отсутствующие в распознанном интерфейсе. Сохранённые профили паролей защищены Windows DPAPI и загружаются при следующем запуске; токены остаются в памяти.

Новая дата прошивки с прежним интерфейсом не требует отдельного разрешения. Полностью новый интерфейс может потребовать добавления правила. Подтверждение настройки режима через API не означает, что ASIC уже набрал рабочий хешрейт. [Как определяется совместимость](development/stock_api_compatibility.md).

**WhatsMiner RPC 3.0.x:** сон, пробуждение, подсветка и перезагрузка разрешаются по
документированному протоколу и ответам устройства. В стандартном наборе есть профиль
«WhatsMiner — все устройства»: логин/пароль `super` / `super`, адреса `*`, как в
официальном демонстрационном коде. На M61 с API 3.0.5 эта пара проверена командой
подсветки. Если пароль API изменён, укажите действующий пароль в общем профиле.
Если на отдельных устройствах
другие пароли, добавьте профили для их IP/подсетей: они имеют приоритет над общим.
При наличии ранее сохранённого набора без общего профиля его можно добавить
в «Доступ к ASIC», указав адреса `*`. Допускаются также аккаунты `user1`–`user3`.
Прежний пустой стандартный профиль WhatsMiner обновляется при загрузке;
пользовательские пароли, отдельные адреса и отключённые профили сохраняются.
Нужен включённый API Write и право на команду;
`root`/`admin` в качестве account нового RPC не подходят. HTTP Digest/Basic
на TCP RPC не влияет. [Подробности и статус испытаний](testing/whatsminer-rpc3-2026-10-01.md).

## Компактная таблица

Ширина столбцов и высота строк переключаются в **Настройки программы → Таблица →
Режим таблицы → Компактный**. Выбор сохраняется между запусками. Столбцы можно
растягивать вручную; запуск и завершение сканирования не сбрасывают их ширину.
Полный текст сокращённой ячейки доступен при наведении.

## Отчёты

- **Excel / CSV** — сохранить результаты в `.xlsx` или `.csv`.
- **Отчёт PDF** — сформировать PDF с настроенными столбцами и сортировкой.
- **Снимок таблицы** — скопировать сводку и видимую часть таблицы в буфер обмена; вставьте в нужную программу.

PDF, CSV и XLSX содержат все результаты сканирования независимо от фильтра отображения. Скриншот содержит видимую область. Столбцы для каждого формата выбираются отдельно в настройках. Журнал событий можно сохранить через **Журнал**.

## Если что-то не работает

| Ситуация | Что проверить |
|---|---|
| Устройства не найдены | Галочки сетей, IP-диапазоны, доступ с ПК, включённый API, пароль и фильтры производителей |
| Неверный диапазон | Номер строки в редакторе, порядок начала/конца, IPv4 и маску |
| Команда недоступна | Выбранные устройства, профиль и статус аппаратной проверки команды |
| Настройки не сохраняются | Сообщение об ошибке, свободное место и доступ на запись в папку настроек |
| Отчёт не создаётся | Папку назначения, её доступность и текст ошибки в журнале |

Для обращения приложите версию программы, Windows, модель и точную прошивку, шаги воспроизведения и обезличенный журнал. [Сбор диагностики](testing/README.md) и [форма ошибки](https://github.com/Drubic8/AgentScanner/issues/new/choose).
