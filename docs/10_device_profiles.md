# Device Profiles

Список поддерживаемых профилей устройств и их основные отличия в управлении.

## 1. Stock Antminer: совместимость API

Для L9, T21, S21 и поддержанных вариантов S21 используется распознавание изученного
веб-интерфейса вместе с форматом текущей конфигурации. Правила находятся в
`miner_scanner/profiles/stock_interfaces.json`. Разные интерфейсы одной модели
могут иметь разные режимы и ключи записи. Дата прошивки не является обязательным
условием такого совпадения. [Описание и ограничения](development/stock_api_compatibility.md).

## 2. Stock Antminer: точные профили

`miner_scanner/profiles/catalog.json` сохраняет особенности телеметрии и команды,
испытанные на конкретных сборках. Наличие `bitmain-work-mode` при чтении само по себе
не определяет ключ записи: это может быть `miner-mode` или `bitmain-work-mode`.
Параметры частоты сохраняются из конфигурации согласно изученному соответствию
полей; значения `100` или пустая строка по названию модели не подставляются.

## 3. VNishProfile
- **Применимость:** Любые устройства с кастомной прошивкой VNish.
- **Признак:** Ответ на `/api/v1/info` или наличие маркера `vnish` в сокет-дампе.
- **Управление:** REST API, авторизация по токену (Bearer) или Digest (в старых версиях).

## 4. WhatsminerRPC
- **Применимость:** Устройства MicroBT (Whatsminer).
- **Признак:** Структурированный успешный ответ `get.device.info`, содержащий модель и `system.api`.
- **Управление:** JSON с четырёхбайтовым little-endian префиксом длины на TCP 4433.
  Для совместимого RPC 3.0.x используются `set.miner.service`, `set.system.led`,
  `set.system.reboot`; авторизация по токену SHA256/Base64, соли и времени.
  Нужны API Write и учётная запись `super` / `user1`–`user3` с подходящими правами.
  [Проверка совместимости и границы аппаратных испытаний](testing/whatsminer-rpc3-2026-10-01.md).

## 5. ElphapexLuci
- **Применимость:** Устройства Elphapex (DG-серия).
- **Признак:** Ответ от 9588 порта или специфических Luci CGI.
- **Управление:** Прямые POST запросы на эндпоинты `/cgi-bin/luci/*` без пароля.

## 6. JasminerDigest
- **Применимость:** Устройства Jasminer (X-серия).
- **Признак:** Успешный экспресс-опрос по 80 порту (веб-интерфейс).
- **Управление:** Digest Auth, специфичные CGI скрипты для подсветки.

## 7. AvalonSocket
- **Применимость:** Устройства Canaan (Avalon).
- **Признак:** Ответ на порт 4028, содержащий `Avalon` или `Canaan`.
- **Управление:** Прямые JSON/Text команды в TCP 4028 (команды типа `ascset`).

## 8. PitBit

Общий профиль `bitmain.pitbit` определяет семейство по структурированному маркеру
PitBit/incm. LED поддерживается при подтверждённом CGI-интерфейсе.
Проверенный профиль `bitmain.pitbit.s21.c074.20240202` дополнительно разрешает
Sleep/Wakeup и Reboot для `Antminer S21_i`, HTTP build от 02.02.2024,
движка `incm.C074` и API `3.1`. Ограничение `match.miner_versions` проверяет
версию движка отдельно от `match.firmware_versions`.
Sleep/Wakeup передают только строковое `bitmain-work-mode` 1/0; успешный `M000`
проверяется повторным чтением. Low/High/HEM не выведены из наличия настроек частоты.
[Результаты аппаратной проверки и ограничения](testing/pitbit-s21-2026-10-03.md).
