# Подключение Яндекс ИИ к ASIC Monitor

Для входа через аккаунт ChatGPT используйте [отдельную инструкцию](user_guide_chatgpt.md).

Эта инструкция относится к текущим исходникам после Windows 2.6.0.
В опубликованном `v2.6.0` есть просмотр логов, но ещё нет вкладки ИИ-анализа.
Для проверки используйте [запуск из исходников](../README.md#запуск-из-исходников)
с установленными зависимостями `desktop`. В Android 2.5.0 ИИ-анализа нет.

Для первого подключения нужны аккаунт Yandex Cloud / AI Studio, каталог и
API-ключ. Анализ выполняется в облаке Яндекса и оплачивается по условиям API.
Обычная пользовательская подписка Алисы не подключается этим способом.
[Различия способов доступа](https://aistudio.yandex.ru/ru/docs/ai-studio/api-ref/authentication).

## 1. Подготовьте аккаунт и каталог

Откройте [Yandex AI Studio](https://aistudio.yandex.cloud/) и войдите в аккаунт.
Если сервис предлагает создать облако, каталог или подключить платёжный аккаунт,
завершите эти действия в интерфейсе Яндекса. Проверьте доступный баланс и квоты
перед отправкой запросов.

Выберите каталог для ASIC Monitor. Нужен его идентификатор, а не название.
В AI Studio его можно скопировать через название каталога в верхней части окна;
в консоли Yandex Cloud он также указан в сведениях о каталоге.

## 2. Создайте API-ключ

В AI Studio нажмите **Создать API-ключ**, задайте понятное описание, например
«ASIC Monitor», и срок действия. Сервис предложит создать сервисный аккаунт с
правами для API. Для отдельного существующего сервисного аккаунта ключ создаётся
через **Доступ → API-ключи**. Проверьте, что права аккаунта и область действия
ключа разрешают генерацию текста в выбранном каталоге.

Сохраните **секретную часть ключа**: именно она нужна программе. Идентификатор
ключа предназначен для управления им и не заменяет секрет. После закрытия окна
Яндекс не показывает секрет повторно. Подробные действия и настройка разрешений
есть в [официальной инструкции](https://aistudio.yandex.ru/ru/docs/ai-studio/operations/get-api-key).

Ключ вводите только в программу. Не отправляйте его в чат, отчёты, скриншоты
или GitHub.

## 3. Заполните настройки ASIC Monitor

Откройте **Настройки → ИИ и диагностика** и укажите:

| Поле | Что указать |
| --- | --- |
| Провайдер | Yandex AI Studio |
| Каталог | Скопированный идентификатор каталога |
| Модель | Для начала `yandexgpt-5.1` |
| API-ключ | Секретную часть созданного ключа |

**Ожидание ответа** задаётся от 5 до 120 секунд, по умолчанию 45 секунд.
Лимит ответа Яндекса — от 64 до 4096 токенов, по умолчанию 1600. Слишком малый
лимит может оборвать заключение: незавершённый ответ программа не принимает.
Эти настройки не рассчитывают заранее стоимость запроса.

Модель можно заменить, если она доступна вашему аккаунту;
[актуальный список](https://aistudio.yandex.ru/ru/docs/ai-studio/concepts/generation/models)
показывает имена и сроки поддержки. Не выбирайте модель только по похожему
названию: её API и права должны соответствовать подключению.

Нажмите **Проверить подключение**. Отправится короткий тестовый запрос без логов
и показаний оборудования. Он может тарифицироваться. Успешная проверка означает,
что выбранные ключ, каталог и модель приняли тестовый запрос; качество
диагностики устройств проверяется отдельно.
После проверки нажмите **Сохранить**. Если вы сохранили настройки раньше,
откройте этот раздел заново для проверки подключения.

API-ключ сохраняется отдельно от обычных настроек в `ai_credentials.dat`, с
шифрованием для текущего пользователя Windows. При переносе программы на другой
ПК или другой аккаунт ключ потребуется ввести заново. Для замены или удаления
ключа используйте этот же раздел настроек. Если ключ уже сохранён, пустое поле
оставляет его прежним. Отмена окна не записывает новый ключ.

## 4. Проанализируйте одно устройство

1. Просканируйте нужный ASIC и откройте **Карточку устройства**.
2. На вкладке **Логи устройства** получите доступный журнал либо откройте
   сохранённый текстовый файл.
3. Перейдите на **ИИ-анализ**. Просмотрите очищенные данные, подготовленные к
   отправке. Если часть большого лога пропущена, это будет указано.
4. Подтвердите отправку и нажмите **Проанализировать**. При необходимости
   отмените ожидание.
5. Изучите наблюдения, ссылки на строки, вероятные причины и следующую проверку.

Заключение можно скопировать или сохранить кнопкой **Сохранить…** в текстовый
файл. В нём остаются название модели, время анализа и SHA256 отправленных данных,
чтобы отличать результаты разных запросов.

Анализ относится к снимку, с которым открыта карточка. Для новых показаний
повторите сканирование и откройте карточку заново. Импортированный файл может
относиться к другому устройству или периоду; программа сохраняет признак импорта.

Автоматическая очистка скрывает известные идентификаторы и секреты, но может
не распознать произвольные личные сведения. Перед отправкой проверьте
предпросмотр. Программа не запускает анализ при обычном сканировании и не
отправляет команду управления ASIC по тексту ответа ИИ.

## Если подключение не прошло

| Ситуация | Что проверить |
| --- | --- |
| Ключ не принят | Вставлена секретная часть, ключ не просрочен и не отозван |
| Нет доступа | Каталог, права сервисного аккаунта и область действия ключа |
| Превышена квота | Лимиты и доступный баланс в Yandex Cloud |
| Модель недоступна | Имя модели и её доступность для выбранного каталога |
| Нет ответа | Интернет, доступ к API Яндекса и время ожидания |
| Ответ не принят | Прочитайте причину и этап проверки: формат заключения или ссылка на отсутствующие данные. Для разбора ошибки сообщите эти сведения; повторный запрос требует нового подтверждения |

После ошибки платный запрос не повторяется автоматически. При тайм-ауте
провайдер мог уже начать обработку; новый запрос может учитываться отдельно.
Для обращения в поддержку достаточно названия модели и безопасного кода ошибки,
без API-ключа и исходных личных данных.

При проблемах системного DNS отмена может ожидать завершения разрешения имени
сервера. После этого действует общий срок ожидания запроса. Программа ждёт
окончания фоновой операции перед закрытием окна, чтобы не уничтожить работающий
поток.
