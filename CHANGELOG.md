# История выпусков

## 2.5.0 — 2026-10-26

- Windows: предварительный параллельный опрос выбранных ASIC перед массовой командой. Проверяются исходный паспорт, профиль API, возможности команды и известные требования доступа. Причина отказа выводится по каждому IP; запись начинается только после явного подтверждения готовой части пакета.
- Новое окно результатов с раздельными признаками принятия API и подтверждённого состояния, подробностями, поиском и фильтром проблем. Повтор допускается только для безопасных исходов и снова требует проверки и подтверждения.
- Сбой одного задания больше не прерывает остальные адреса. Сохраняются исходный fingerprint выбранной строки и уже полученное подтверждение API при аварии очереди. Закрытие программы останавливает очередь и не разрешает новую отправку.
- HTTP 5xx после управляющего запроса считается неопределённым исходом, а не основанием повторить запись. Для команд с проверкой результат уточняется отдельным чтением API.
- Настройки шрифта и отдельных размеров интерфейса и таблиц: установленные шрифты, компактные выпадающие списки, ручной ввод размеров, предпросмотр, сброс и сохранение рядом с EXE. Высота строк и ширина боковой панели подстраиваются под текст.
- Перевод повторяющихся полей счётчиков больше не вызывает ошибку регулярного выражения. Новые окна переведены на английский.
- CSV/XLSX: значения, полученные от ASIC, сохраняются как данные; потенциальные формулы нейтрализуются при экспорте.
- Android: версия 2.5.0 (20500), обновлённое общее ядро; мобильный интерфейс сохраняет прежний набор функций. APK остаётся с тестовой подписью.
- Временные артефакты GitHub Actions хранятся 3–7 дней; опубликованные файлы Releases сохраняются отдельно.

[Описание версии](docs/releases/2.5.0.md)

## 2.4.1 — 2026-10-20

- Windows: перетаскивание сетей и папок меняет порядок и вложенность. Добавлены стрелки и сочетания Alt+↑/↓/←/→; перенос в папку остаётся доступен для нескольких выбранных строк.
- Сохраняются порядок, содержимое папок и галочки сетей; запрещены циклы и совпадения имён внутри папки. Ошибка записи не меняет сохранённое дерево.
- Ширина видимых столбцов подбирается по содержимому после сканирования. Автоподбор можно отключить в настройках таблицы или меню заголовка. Двойной щелчок по границе подбирает отдельный столбец; длинные worker больше не ограничены прежним лимитом сохранения 1200 px.
- Новые элементы управления переведены на английский. Android синхронизирован до 2.4.1 (20401), с исправлением состояния KS5 в общем ядре; изменения дерева и столбцов относятся к Windows.

- Исправлено ложное состояние «Сон» у Antminer KS5/KS5 Pro Stock: положительный текущий хешрейт имеет приоритет над сохраняющимся значением `bitmain-work-mode = 1`. Средний хешрейт не считается доказательством текущего майнинга. Проверено чтением на двух KS5 с прошивками апреля и мая 2024 года; добавлены обезличенные снимки и регрессионные тесты.

[Описание версии](docs/releases/2.4.1.md)

## 2.4.0 — 2026-10-13

- Добавлено сканирование Antminer A3 Stock: модель, прошивка, Blake2B, Real/Avg в GH/s, температуры и обороты вентиляторов. Обработан подтверждённый дефект JSON в старом STATS.
- Добавлен профиль Goldshell MCB, проверенный чтением на HS5 / Stock 2.2.1: сумма хешрейта плат, выбранный алгоритм SC/HNS, датчики, активный пул, worker и состояние LED.
- Алгоритм Goldshell определяется по текущему выбору API; Blake2B-Sia и Blake2B+SHA3 учитываются отдельно от Blake2B A3.
- Goldshell включён в фильтр «Остальные» в Windows. Нули датчиков сохраняются, отсутствующие показатели не заменяются нулями, повторяющиеся вентиляторы не дублируются по числу плат.
- Добавлены обезличенные аппаратные снимки и регрессионные тесты. Управление Goldshell пока не подтверждено; аппаратная проверка A3 в этом выпуске касается чтения.
- Android: исходники общего ядра обновлены, `versionName = 2.4.0`, `versionCode = 20400`; сборка и аппаратная проверка нового APK выполняются отдельно.

## 2.2.4 — 2026-10-05

- Windows stores network folders, preferences and encrypted ASIC profiles beside the actual EXE, independent of the working directory and PyInstaller extraction path.
- One-time migration selects the newer valid sidecar/AppData file, preserves replaced sidecars in `.settings-backup`, and leaves old AppData intact. Later launches never re-import old data.
- Normal startup now enables automatic persistence of language, theme and table layout; synthetic UI checks remain isolated.
- Atomic writes retain the previous file on failure. A non-writable folder produces a visible startup error instead of redirecting settings elsewhere.
- Added nested-folder, export-path, restart, migration and packaged EXE regression checks. Android version is 2.2.4; Android storage and miner APIs are unchanged.

## 2.2.3 — Стабильная идентификация VNish

- Исправлены ложные `skipped` при массовой подсветке и других командах VNish.
- Идентификация из `/api/v1/info` не зависит от порядка ответов HTTP/TCP и не подставляет SN платы.
- При наличии актуальной прошивки и SN/MAC исчезновение CGMiner API не считается сменой устройства.
- Реальные изменения модели, прошивки, SN и MAC продолжают блокировать запись.
- Общее исправление включено в Windows и Android; добавлены регрессионные проверки.
